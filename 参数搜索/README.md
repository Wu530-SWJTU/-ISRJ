# 参数搜索（搜索线·独立项目）

**分支：`参数搜索`　创建：2026-09-12**

把波形–滤波器联合设计当作**代价函数构造工具**，反向搜索 ISRJ 参数（当前一维瞄准
窗口起点 `t_0`，后续扩展到占空比 `d`、采样周期 `T_s`），使候选参数逼近真实参数。

## 与复现线的关系

- **复用**：本项目的脚本调用 `isrj_joint_design/`（仓库根，论文复现包）的公开接口，
  用于联合设计与指标计算。
- **不修改**：`isrj_joint_design/` 与 `tests/` 是**复现线**，以 PRD 为唯一权威，本项目
  一行不改（接口清单见 `docs/搜索线规格说明.md` §1.1）。
- **本项目产物全部在本文件夹内**（脚本 / 结果 / 文档），与复现线的 `scripts/`、
  `参数误差/` 物理分开。

## 基线参数（v2 · 对齐 Zhou 2026）

**唯一来源：`scripts/baseline.py`**（脚本禁止再硬编码参数）

| 参数 | 值 | 说明 |
|---|---|---|
| `B` / `fs` | **10 MHz / 10 MHz** | `fs = B`，1 采样点 = **0.1 μs** |
| `T_p` / 码长 `L` | **25.6 μs / 256** | `L = B·T_p` |
| `t_0` 窗口起点 | **2 μs**（20 点） | 用户指定 |
| `T_L` 截取长度 | **1.5 μs**（15 点） | |
| `T_s` 采样周期 | **6.4 μs**（64 点） | 码内 4 片 |
| `d` 占空比 | **0.234**（= `T_L/T_s`） | 派生量 |
| 干扰峰值约束 | **−80 dB**（`b_min = b_max·10⁻⁴`） | 论文口径 |
| 误差范围 | **±0.5 μs** | 论文 Fig.12 |
| 初始化 / 种子 | `random_phase` / 0 | 不继承论文的通信波形初始化 |

口径决策（2026-09-25）：信号侧与干扰侧照搬论文；窗口起点用 2 μs；约束取 −80 dB；
**保持零延迟原位模型**（`y_j = x⊙j`，不含论文的延迟转发）。
v1（自建 800 点体系）结果已归档到 `结果/_v1_自建800点/`。

## 已有结果（v2）

- **三对联合误差图**：`结果/联合误差/联合误差_三对总览.png`（2×3：上排 3D、下排等高线，统一色标）
  - `t_0 × T_s`、`t_0 × T_L`、`T_L × T_s` 三对**都是针状闭合谷**，谷底 −80 dB 就在设计点
  - 数据 JSON + `结果表.md` 同目录；脚本 `run_joint_error_maps.py` + `plot_joint_error_summary.py`
- **三维平滑性分析**：`结果/平滑性/平滑性分析_三维.png`
  - 分辨率下限 = 1 采样点（0.1 μs）；0.1 μs 的误差就抬升 47 dB（针状）
  - ±0.5 μs 的小盒子里**出现 3 个局部极小**（位移+缩窗可重新对齐采样支撑）
  - 微粗糙度：`t_0`/`T_s` 10% 步长反向、`d` 30%（单点尺度方向不可靠）

## 运行

```bash

.venv/Scripts/python.exe 参数搜索/scripts/run_joint_error_maps.py   # 三对联合误差数据（含自动设计，约 1 分钟）
.venv/Scripts/python.exe 参数搜索/scripts/plot_joint_error_summary.py  # 合成 2×3 总览图（秒级）
.venv/Scripts/python.exe 参数搜索/scripts/run_smoothness_analysis.py   # 平滑性分析（约 1 分钟）
.venv/Scripts/python.exe 参数搜索/scripts/baseline.py                  # 打印当前基线
```
