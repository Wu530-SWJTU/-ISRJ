# 参数搜索（搜索线·独立项目）

**分支：`参数搜索`　创建：2026-09-12**

把波形–滤波器联合设计当作**代价函数构造工具**，反向搜索 ISRJ 参数（当前一维瞄准
窗口起点 `t_0`，后续扩展到占空比 `d`、采样周期 `T_s`），使候选参数逼近真实参数。

## 与复现线的关系

- **复用**：本项目的脚本调用 `isrj_joint_design/`（仓库根，论文复现包）的公开接口，
  用于联合设计与指标计算。
- **不修改**：`isrj_joint_design/` 与 `tests/` 是**复现线**，以 PRD 为唯一权威，本项目
  一行不改（接口清单见 `docs/搜索线规格说明.md` §1.1）。
- **本项目产物全部在本文件夹内**（脚本 / 结果 / 文档），与复现线的 `scripts/`、
  `参数误差/` 物理分开。

## 基线参数（本项目默认口径）

| 参数 | 基线值 | 备注 |
|---|---|---|
| `t_0` 窗口起点 | **2.5 μs** | 窗口 `[2.5, 5) μs`；复现线默认 0 μs，本项目显式传入 |
| `d` 占空比 | 0.25 | `= T_L / T_s` |
| `T_s` 采样重复周期 | 10 μs | |
| `T_L` 截取长度 | 2.5 μs | `= d·T_s`，派生量 |
| `N` 码长 | 800 | 论文规模（`N = B·T_p`） |
| 波形初始化 | `random_phase` | 与复现线默认一致 |
| 随机种子 | 0 | 记录在 JSON，保证可复现 |

> ⚠️ 不要改 `isrj_joint_design/params.py` 的默认 `tau_offset`：那是 PRD 验收基线
> （`tests/test_params.py` 有断言）。本项目基线一律显式传参。

## 已有实验

### 实验 1：归一化电平 – 窗口起点 t_0（`scripts/run_t0_sweep.py`）

设计假设 `t_0 = 2.5 μs`（N=800、M=100、random_phase、seed=0），实际窗口起点
偏离基线 `ε ∈ [−2.5, +2.5] μs`，共 51 点。

- 设计指标：PSL **−31.99 dB**、处理增益损失 **−2.66 dB**、ISRJ 零延迟 **−30.00 dB**、
  约束残差 (1.3e−09, 7.9e−08)
- 结果：谷底精确落在 `t_0 = 2.5 μs`（−30.00 dB，C = 0.0316），两翼单调上升，
  近对称（ε = ±1 μs 处 −15.77 / −16.81 dB）；ε = ±2.5 μs 退化到 −9.45 / −9.96 dB
- 产物：`结果/窗口起点/`（`归一化电平_t0.png`、`t0_sweep.json`、`结果表.md`）
- 图：横轴 = **t_0 误差 ±2.5 μs**（谷底在 0 处，左右各 2.5 μs）；纵轴左 = 归一化电平（dB，
  含 −30 dB 基准线），右 = 积分电平 IL

## 运行

```bash
# Windows 下务必用 .venv（勿用裸 python）
.venv/Scripts/python.exe 参数搜索/scripts/run_t0_sweep.py            # 复用已存设计，秒级
.venv/Scripts/python.exe 参数搜索/scripts/run_t0_sweep.py --redesign # 重跑联合设计（约 50 s）
.venv/Scripts/python.exe 参数搜索/scripts/run_t0_sweep.py --min -1 --max 1 --step 0.05  # 换扫描范围
```
