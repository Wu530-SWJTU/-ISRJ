## 1. 泄漏的精确分解

零延迟干扰输出（未归一化幅度）可以精确拆成两项：

```
h^H(x ⊙ j_actual) = b_min + Σ_{n ∈ 位移样本} ± conj(h[n])·x[n]
                     ↑约束钉死          ↑只由"实际窗口相对设计窗口换了哪些样本"决定
```

- `b_min = 25.3`（−30 dB）由设计硬约束钉死，误差再大也不动
- 已逐点数值验证：δ = −50 … +50 点，逐样本求和与直接计算**逐位一致**
- **单样本泄漏 ≈ |h[n]|**（幅度），实测平均约 0.6，相对 `b_max = 800` 仅 −62 dB
- 滤波器能"吃下"约 **42 个位移样本**才开始明显变差 ⇒ 曲线只能平缓爬升

**为什么不会"突然崩塌"**：位移是逐样本累积的，泄漏近似正比于位移样本数
（实测每样本 0.50–0.74），所以 dB 上是一条平滑上升的曲线。唯一突变边界是
**物理边界**（窗口跨周期，`t_0 > 7.5 μs`），那不是灵敏度。

**已排除的两个猜测**：

| 猜测 | 实测结论 |
|---|---|
| 是归一化造成的 | 分母 `|h^H x| = 800` 是常数，除以常数只平移曲线（+58.06 dB），**形状不变** |
| 是 ε（ILs 权重）太偏 | ε = 0.1 / 0.5 / 0.9 三档重设计，V 几乎完全重合（±0.1 μs 处 −26.19 / −26.68 / −25.91 dB）⇒ 不是"优化得太鲁棒" |

## 2. 决定陡度的量：码内采样窗口数 K

```
每单位参数误差的位移样本数 = 2 ×（误差点数）× K ，   K = N / (T_s·fs) = 码内窗口数
```

**实测**（**占空比固定 0.25**，`T_L = 0.25·T_s` 随 `T_s` 缩放；`t_0` 基线 = `T_s/4`；扫描 ±1.25 μs，步长 0.05 μs = 1 点）：

| 指标 | K=4（T_s=10 μs、T_L=2.5 μs） | **K=8（T_s=5 μs、T_L=1.25 μs）** |
|---|---|---|
| 占空比 | 0.25 | 0.25（固定不变） |
| 谷底 | −30.00 dB | −30.00 dB（约束钉死） |
| ±0.05 μs 抬升 | 1.80 dB | **3.10 dB** |
| ±0.25 μs 抬升 | 4.82 dB | **8.35 dB** |
| ±0.5 μs 抬升 | 8.22 dB | **12.97 dB** |
| ±1.0 μs 抬升 | 13.19 dB | **18.12 dB** |
| PSL | −31.99 dB | **−32.05 dB（几乎不变）** |
| 处理增益损失 | −2.66 dB | −3.00 dB |
| 设计耗时 | 49.7 s | 44.1 s |

**结论：K 翻倍 ⇒ 陡度约 1.7 倍（小误差处 1.80 → 3.10 dB），而 PSL 几乎不动。**

⚠️ **修正一条早先的结论**：上一版实验固定 `T_L = 2.5 μs`（于是 K=8 时占空比被动地从 0.25 涨到 0.50），
得到"陡度翻倍但 PSL 差 4.9 dB"。**占空比固定后重测，那 4.9 dB 的 PSL 代价来自占空比翻倍，不是窗口数增多的代价**
——窗口数本身几乎不花 PSL。教训：比较实验必须控制住派生量（此处 `d = T_L/T_s`）。

产物：`参数搜索/结果/采样周期对比/`（脚本 `run_window_count_compare.py`）。

## 3. 边界与待续

- **硬边界**：必须 `T_L < T_s`（占空比 < 1），否则 `x⊙j → x`，
  `x^H h = b_max` 与 `x_j^H h = b_min` 两条硬约束冲突、无解。
  当前 `T_L = 2.5 μs` ⇒ **K < 16**。
- **待试**：K = 12（`T_s` = 3.33 μs，占空比 0.75）逼近极限的表现。
- **另一方向**：缩小 `T_L`（须同时重新定 `t_0` 基线；若保持 `d` 不变则窗口数也增加，若保持
  `T_s` 不变则 K 不变、按机理陡度基本不变）。
- **另一次观察**（该实验产物已按要求删除、未留档）：收紧零延迟约束 `peak_interf_db`
  （−30 → −50 / −60 dB）也会让**谷底尖端**变尖（±0.1 μs 抬升 3.32 → 16.45 → 25.42 dB），
  且 PSL / 损失代价很小（−32.0 → −32.5 dB、−2.66 → −3.24 dB）。待续时可复现。
- **解读（写论文时要交代的权衡）**：
  **尖 = 设计对参数敏感 = 部署脆弱；平缓 = 部署鲁棒但参数可辨识性弱。**
  搜索算法需要的是"有梯度"，不是"无限尖"——这两件事要分开讲。
