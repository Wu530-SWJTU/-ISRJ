> 本文件 §1 是**与口径无关的机理**；§2–§4 是 **v2 实测**；§5 记录 v1→v2 被推翻的结论。

## 1. 泄漏的精确分解（机理，与口径无关）

零延迟干扰输出（未归一化幅度）可精确拆成两项：

```
h^H(x ⊙ j_actual) = b_min + Σ_{n ∈ 位移样本} ± conj(h[n])·x[n]
                     ↑约束钉死          ↑只由"实际窗口相对设计窗口换了哪些样本"决定
```

- 第二项的数量级 = **位移样本数 × 单样本泄漏 |h[n]|**，逐样本求和与直接计算**逐位一致**（v1 已逐点验证）
- **位移型误差**（`t_0` 齐步平移、`T_s` 逐窗口累积）⇒ 替换样本 ⇒ 两边都变差 ⇒ **V 型**
- **包含型误差**（`T_L`/占空比 变宽变窄）⇒ 增删样本 ⇒ 曲线形状取决于 `b_min` 有多深（见 §5）

## 2. v2 实测：谷是"针状"的

设计对（v2）：PSL −28.82 dB、处理增益损失 −3.18 dB、零延迟干扰 **−80.00 dB**、设计耗时 5 s。

| 误差 | 零延迟电平 | 相对谷底抬升 |
|---|---|---|
| 0（设计点） | −80.00 dB | 0 |
| **±0.1 μs（= 1 个采样点）** | **−32.8 / −32.4 dB** | **+47 dB** |
| ±0.5 μs | −21.0 / −19.8 dB | +59 / +60 dB |
| ±1.0 μs | −14.1 / −13.6 dB | +66 dB |

**谷宽只有 1 个采样点**。对比 v1（−30 dB 约束）：同样偏 1 个采样点，v1 只抬 3.3 dB、
v2 抬 **47 dB** ⇒ **约束越深，谷越尖**，这一条从"预测"变成了实测。

## 3. 分辨率下限：1 个采样点（量化台阶）

细扫（跨度 ±1 采样点、410 步）中 **99.5% 的步长电平不变**，只在新跨过整数采样点时跳变。
v2 下 1 采样点 = **0.1 μs**（`d` 方向为 1/(`T_s·fs`) = 1/64 ≈ 0.0156）。

⇒ 小于 0.1 μs 的调整读不出任何变化；**搜索步长与有限差分步长都必须 ≥ 1 采样点**。

平台的半宽恰好是 **±0.5 个采样点**（`round()` 的格子边界在 x.5 处），且这个对称性**依赖
基线落在整数采样点上**：v2 的 `T_s` = 6.4 μs 正好是 64 个点 → 容差 [−0.05, +0.05] μs 对称；
若基线取 6.37 μs（63.7 点）→ 格子 `[63.5, 64.5)` 对应误差 [−0.02, **+0.08**] μs，左右不对称。

**建模决策（2026-09-25 用户定）**：接受量化台阶（方案 A），**不**为消除台阶而把干扰机采样时刻
改成"分数采样点"（方案 B）。理由：论文（Zhou 2020/2026）本身就假设干扰机采样间隔是雷达采样
间隔的整数倍，量化是这一离散约定的固有结果；改成分数延迟虽更接近真实 DRFM，但会脱离论文口径
且需重建 `H_j`/`X_j`。若将来确需连续曲线，再启动方案 B。

## 4. v2 新发现：**多谷**（对搜索最要命的一条）

在 ±0.5 μs 的小盒子里、11×11×11 网格上扫出 **3 个严格局部极小**：

| 位置（`t_0` 点, `d`, `T_s` 点） | 含义 |
|---|---|
| (0, 0, 0) | 真设计点 ✓ |
| (0, **−4 点**, 0) | 起点对、**截取长度短 4 点的伪谷** |
| (**+4 点**, **−4 点**, 0) | **起点后移 4 点 + 截取短 4 点**的伪谷 |

**机理**：整数采样下"**移位 + 缩窗**"可以重新对齐采样支撑，凑出另一个低电平。
换句话说，只要 (起点, 片长) 的组合能近似复现设计的采样集合，就会出现伪谷。

**含义**：爬山法 / 二分 / 黄金分割都可能掉进伪谷 ⇒ 搜索必须先**粗网格全局扫描**定位主谷，
再做局部精搜。这条在 v1（−30 dB）下不存在（当时网格内 0 个局部极小）。

其他 v2 指标：

| 指标 | `t_0` | `T_s` | `d` |
|---|---|---|---|
| 微粗糙度（1 采样点步长的方向翻转率） | 10% | 10% | **30%** |
| 单边斜率 @设计点（±1 点，dB） | +47.6 / +47.2（真 V） | +46.2 / +15.7（真 V） | +52.0 / +48.5（真 V） |
| Hessian 特征值（dB/点²） | — | 60.9 | 92.2（`t_0`） | 104.1 |

三对联合误差图（`结果/参数调制/联合误差/`）在 ±0.5 μs 范围内**三对都是闭合谷**。

## 5. v1 → v2 被推翻的一条结论（务必注意）

| 结论 | v1（−30 dB，800 点） | **v2（−80 dB，256 点）** |
|---|---|---|
| `T_L`/占空比那一维 | **单调**、极小在边界 ⇒ "d 不能进搜索向量" | **有内部极小**（闭合谷）⇒ 该结论**作废** |

**为什么翻转（已量化）**：零延迟量 `b_min = h^H(x⊙j)` 是**一串项的和**，方向由"抵消有多深"决定：

| | v1（−30 dB，N=800） | v2（−80 dB，N=256） |
|---|---|---|
| `b_min` | 25.3 | 0.0256 |
| 各项模长之和 `Σ\|conj(h)x\|` | 118 | 38.75 |
| **抵消程度 `b_min/Σ\|项\|`** | **0.215**（浅） | **0.0007**（≈1/1400，几乎完全抵消） |
| 窗口**变窄 1 点**后 | 24.52 → **0.97×（变小，变好）** | 0.1567 → **6.12×（变大，变差，+15.7 dB）** |

- **浅抵消**（`b_min` 与 `Σ\|项\|` 同量级）⇒ 和 ≈ 项数 × 单项 ⇒ 删项让和**变小** ⇒ 越窄越好 ⇒ **单调**
- **深抵消**（靠精确抵消撑出极小残差）⇒ **任何改变采样集合的动作都会破坏抵消、让残差暴增** ⇒ 两边都变差 ⇒ **V 型**

（v2 的"变窄 1 点 = +15.7 dB"与 `结果/参数调制/占空比扫描/` 实测的第一点 15.74 dB 一致。）

**教训**：**"某个参数能不能搜"依赖于 `b_min` 的深度**——换约束深度就等于换了一套可辨识性结论，
不能跨口径引用。

## 6. 对搜索算法的硬约束（v2）

1. 步长 ≥ 1 采样点（0.1 μs），小于它毫无意义；
2. **先粗网格全局扫**（步长 ≤ 1 采样点，否则跳过针状谷），再局部精搜 —— 因为存在伪谷；
3. `d` 方向单点尺度的方向 30% 是反的 ⇒ 该维要么粗步长、要么先平滑；
4. 判断"是不是谷底"要**左右分开看**（设计点是 `|·|` 型拐点，中心差分 Hessian 会把单调方向误判为极小）。

**解读（写论文时的权衡）**：尖 = 设计对参数敏感 = 部署脆弱；平缓 = 部署鲁棒但可辨识性弱。
搜索需要的是"有梯度且**谷底唯一**"，不是"无限尖"。
