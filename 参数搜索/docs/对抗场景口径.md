## 2. 干扰模型（经典 ISRJ 重复转发）

**信号级**（切片 s 在 `[t₀+s·T_s, t₀+s·T_s+T_L)` 采样，采样结束立即重复转发 R 次）：

```
y_jam = Σ_{r=1}^{R} shift_{r·T_L}( x ⊙ j )
```

**矩阵链**：

```
Y_jam = ( Σ_{r=1}^{R} S_{r·T_L} ) · diag(j) · x
脉压输出端  H_j = H · ( Σ_{r=1}^{R} S_{r·T_L} ) · diag(j)
```

**参数**（采样点）：采样函数 j = 4 片，起点 **20**（2 μs）、片长 **15**（1.5 μs）、周期 **64**（6.4 μs）；
转发次数 **R = 3**，假目标位于 **+1.5 / +3.0 / +4.5 μs（= +225 / +450 / +675 m）**。

**两条物理约束**：

1. **占空比** `(1+R)·T_L ≤ T_s`——采样 1 片再转发 R 次，合计不能超过周期。
   基线 `(1+3)×1.5 = 6.0 ≤ 6.4` ⇒ **R 最大为 3**（R=4 需 7.5 μs，放不下）。
2. **假目标必须在真目标之后**——**仅对自卫干扰成立**：转发必须先收到再发出。
   支援干扰（`R_j ≠ R_t`）下公共平移 `Δ0 = 2(R_j−R_t)/c` 可正可负，假目标能跑到真目标前面。
   **本场景不做支援干扰。**

**与搜索线原位模型的关系**：搜索线用零延迟原位 `y_j = x⊙j`（干扰落在真目标自己的距离单元上，
没有假目标）；本场景多一个移位算子 `(Σ_r S_{r·T_L})`，才产生距离维上的假目标串。

## 3. 联合设计（已知精确干扰）

**问题**（把复现线 PRD 的交替优化从 2 条约束推广到多约束）：

```
min_h  h^H P h    s.t.  ⟨h, x⟩ = b_max，  ⟨h, v_ℓ⟩ = b_min   (ℓ ∈ L)
min_x  x^H Q x    s.t.  同左 + PAPR 约束
```

- **约束 lag 集** `L = {0} ∪ {各假目标 lag}` —— **`ℓ = 0` 必须包含**（真目标距离单元），
  否则干扰泄漏到目标 bin 会把真目标拽偏。
- **约束向量**（推导要点）：干扰 J = Σ_r S_{d_r}(x⊙j) 在 lag ℓ 处的输出为
  `Σ_r ⟨h, S_{d_r−ℓ}(x⊙j)⟩`，故

  ```
  v_ℓ = Σ_r S_{d_r−ℓ}( x ⊙ j )       约束 ⟨h, v_ℓ⟩ = b_min
  g_ℓ = j ⊙ Σ_r S_{ℓ−d_r}( h )       （x 空间对偶，供 ADMM 用）
  ```

  单份且 ℓ=0 时退化为 PRD 原式 `v = x⊙j`（已验证 R=1 时 P/Q 与 PRD 逐位相同）。

- **目标矩阵**（多份转发**必须**按移位和重推，否则约束点之外会抬峰）：

  ```
  P = ε (T_h − h h^H) + (1−ε) · diag(j) · Toeplitz(q_h) · diag(j)
  Q = ε (T_x − x x^H) + (1−ε) · Toeplitz(q_u)
  q_h[τ] = Σ_{r,r'} r_h[τ + d_{r'} − d_r]        （移位和核，A = Σ_r S_{d_r}）
  q_u[τ] = Σ_{r,r'} r_{x⊙j}[τ + d_r − d_{r'}]
  ```

  两式恒等式 **`x^H P x == h^H Q h` 机器精度成立**（实测 1.15e-16）。
  单份时 q = 原自相关 ⇒ 退化为 PRD 的 `diag(j)T_h diag(j)`。

- **求解器**：`scripts/scene_joint_design.py`
  - 滤波器：`h = Q^{-1} C (C^H Q^{-1} C)^{-1} b`，`C = [x, v_1..v_R]`，`b = [b_max, b_min×R]`
  - 波形：ADMM，对偶变量 `ν` 由标量扩为 R 维，`A = 2P + 2ρI + ρ h h^H + ρ Σ_ℓ g_ℓ g_ℓ^H`

**设计参数**（沿用搜索线基线）：`b_max = N = 256`、`b_min = N·10^(−80/20)`（**−80 dB**）、
`ε = 0.5`、`η = 1.1`、`ρ = 5000`、`δ = 1e-4`、`M = 100` 轮、初始化 random_phase/seed 0。

**实测设计指标**：约束残差 主瓣 2.0e-9 / 干扰 3.3e-5；PSL −30.13 dB；
处理增益损失 **2.91 dB**（`||h||² = 500` vs 匹配滤波的 256）；耗时约 4.6 s。

## 4. ⚠️ 两个口径别混（最容易出错的地方）

| 口径 | 干扰幅度 | 无误差时的干扰电平 |
|---|---|---|
| **设计口径** | `a_j = 1`（不含 J/S） | **−80.00 dB**（= 约束 b_min/b_max） |
| **场景口径** | `a_j = 10^(10/20)`（J/S=10 dB） | **−70.00 dB** |

设计对干扰幅度**尺度不变**（约束是比例），所以两个口径只差一个 J/S。
**报数时必须注明是哪个口径**——设计日志写 −80、场景图写 −70，都是对的。

**另一个易混点**：距离像上的**可见下限**不是干扰，而是

```
假目标位置的可见电平 = max( 干扰 , 真目标旁瓣 , 输出噪声底 )
                                 ↓          ↓
                           −34 dB 量级   −31.18 dB
```

Δ=0 时干扰被压到 −70/−80 dB，**远在这两者之下**，所以距离像上看不见假目标——
这是"设计生效"的表现，不是"没压住"。要展示压制效果，必须同时画**干扰单独**曲线。

## 6. 关键实测结论

### 6.1 无误差时（设计口径 −80 dB / 场景口径 −70 dB）

三个假目标处的分量分解（Δ=0）：

| 假目标 | 真目标旁瓣 | 干扰（设计后） | 噪声底 |
|---|---|---|---|
| FT1 (+1.5 μs) | −33.7 | **−70.0** | −31.2 |
| FT2 (+3.0 μs) | −38.9 | **−70.0** | −31.2 |
| FT3 (+4.5 μs) | −37.4 | **−70.0** | −31.2 |

⇒ 干扰被压到旁瓣底以下 36 dB，**假目标在距离像上不可见**。

### 6.2 参数误差下的口径（⚠️ 2026-10-01 用户更正，表见下）

**设定：雷达对干扰参数的估计有误差，干扰机始终是基线参数。**

| | 谁变 | 后果 |
|---|---|---|
| ❌ 早期（写错） | 干扰机真实参数偏离 | 假目标跟着平移、±5 档转发次数掉到 2、第三个假目标消失 |
| ✅ **现行** | **雷达的设计假设偏离** | **假目标固定在 +1.5/+3.0/+4.5 μs、恒为 3 个**；雷达把零陷钉在错的 lag 上 |

实现要点：**每一档误差都要重新设计一次**（雷达用错的 θ̂ = θ* + Δ 造掩膜、
算转发时延 `r·T_L̂`、钉零陷），再对**固定不变的真实干扰机**评估。
见 `scripts/run_scene_error_sweep_3param.py::design_for`。

两处指标不同，别混：
- 脚本的**打印表 / JSON** = **干扰单独**（无噪声、无真目标）→ 反映设计把干扰压到多低
- 三张误差图的**标注数字** = 距离像曲线在该点的值（含真目标旁瓣与噪声）→ 反映雷达看得见什么

### 6.2b 修正后的实测（场景口径 = 设计口径 + J/S 10 dB；干扰单独，取三个假目标最差值）

| Δ(采样点) | t₀ | T_L | T_s |
|---|---|---|---|
| **0** | **−70.00** | **−70.00** | **−70.00** |
| −1 | −21.2 | −16.4 | −16.2 |
| +1 | −20.0 | −23.0 | −17.5 |
| −5 | −7.9 | −6.3 | −3.6 |
| +5 | −6.6 | −24.1 | −5.1 |

**三个假目标在每一档都在**（位置固定），这是修正设定后最主要的改善。

**三条结论**：

1. **一个采样点就崩**：−80 → −20 ~ −30 dB（跳变 50 dB），与搜索线 W1 实测的
   "谷宽 1 采样点、偏 0.1 μs 抬升 47 dB"**一致**。校验点：Δ=10 时本场景 −14.09 dB
   vs W1 的 −14.1 dB，精确吻合。
2. **T_L 误差多一重伤害**：`T_L` 变了 ⇒ 转延时延 `r·T_L*` 跟着变 ⇒ **假目标整体平移到
   别的距离上**，而零陷留在原地。所以 T_L 偏 +1 点（−22.2 dB）比 t₀ 偏 +1 点（−29.9 dB）
   更差 7.7 dB。**这是"转发时延 = 切片长度"的直接后果**，零延迟模型里不存在这一维。
3. **占空比约束会自动削减转发次数**：`T_L` 偏 +5 点（片长 2.0 μs）或 `T_s` 偏 −5 点
   （周期 5.9 μs）时 R 从 3 降到 2，假目标个数也变——这两档不能与其他档直接比
   "单个假目标电平"。

## 7. 决策记录

| 日期 | 决策 | 说明 |
|---|---|---|
| 2026-10-01 | 波形用**随机相位**（非 LFM） | 先试过 LFM：其匹配滤波旁瓣为零（CAZAC），但时频耦合会把 m≠0 的假目标压到 −24 dB 以下，出不来假目标串 |
| 2026-10-01 | J/S 15 → **10 dB** | 15 dB 时假目标反超真目标 3.9 dB |
| 2026-10-01 | 假目标数 **R=3** | 受 `(1+R)·T_L ≤ T_s` 限制，R=4 物理上放不下 |
| 2026-10-01 | 干扰模型从"整集重放"改 **"边采样边转"** | 前者可任意指定各份时延（含负延迟），不符合转发式干扰机时序 |
| 2026-10-01 | **自卫干扰**（暂不做支援干扰） | 支援干扰需引入新参数 `R_j`（干扰机距离），留待后续 |
| 2026-10-01 | CFAR **停用但保留脚本** | 局部/全局 CFAR 在密集假目标 + 旁瓣平台下都难以同时满足"全检出 + 零虚警" |
| 2026-10-01 | WJPS 展宽**暂缓** | 用户决定 |

## 8. 已知局限（如实记录）

1. **约束点之间会抬峰**：约束只钉在离散 lag 上（0/15/30/45），零陷之间干扰响应可回升到
   −23 dB。加密约束（0~45 全钉）能把带内压到 −70 dB，但能量会挪到带外、PSL 恶化到 −21.9 dB。
   调 ε 几乎无效（0.5→0.15 只改善 1.3 dB）。
2. **假目标的可见性受旁瓣底限制**：设计对的 PSL 是 −30 dB，假目标压到旁瓣底以下就和
   正常旁瓣结构无法区分了。
3. **噪声放大**：失配滤波 `||h||² = 500`，输出噪声底从 −34.1 抬到 −31.2 dB（代价 2.91 dB）。
