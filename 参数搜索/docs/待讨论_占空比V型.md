## 1. 用户的质疑

> 占空比的估计误差，本质上会导致实际能干扰信号与滤波器做匹配滤波的总值减少 ——
> 这是因为包含这个范围的一个更大范围的总值固定在了 −30 dB。现在这个范围更小，
> 那么应该会导致匹配滤波求和项减少，自然会导致幅度值小于 −30 dB。
> 同样这个道理可运用于 −80 dB。**不可能会出现 −30 dB 不是 V 而 −80 dB 是 V 的情况，
> 都不会是 V。**

后续补充的两问：

- "删掉的项里负的比正的多，幅度就该下降吧？"
- "如果负的多，匹配滤波的值总体就是负的了，这符合实际的匹配滤波吗？"

## 2. 实测结论（与机理之争无关）

| 约束 | 曲线形态 | 最低点位置 |
|---|---|---|
| **−30 dB** | **非 V**：左支几乎平/缓降，最低点在**最窄**的边界 | Δd = −0.0781（−33.10 dB） |
| **−80 dB** | **V**：谷底唯一落在 Δd = 0（−80.00 dB），左右各偏 1 个采样点即 +15.7 / +46.2 dB | Δd = 0 |

数据：`结果/参数调制/占空比扫描/结果表.md`（−80 dB）、`结果表_30dB.md`（−30 dB）。
同一套 256 点系统（B = 10 MHz、L = 256、T_L = 1.5 μs、T_s = 6.4 μs、t_0 = 2 μs），只差约束深度。

## 3. 目前已给出的解释（用户尚未接受）

判据只有一比：**少采一个采样点时，"被拿掉的那几项之和" 与 "设计点的总和" 谁大。**

| | 被拿掉的项之和 | 设计点总和 | 结果 |
|---|---|---|---|
| −30 dB | 0.7753 | 8.0954 | 拿走的更小 ⇒ 剩下的更小（8.095 → 7.637）⇒ 越窄越好 ⇒ **非 V** |
| −80 dB | 0.1381 | 0.0256 | 拿走的更大（5.4 倍）⇒ 剩下的必然更大（0.026 → 0.157）⇒ 两边都差 ⇒ **V** |

数学依据（三角不等式，**不含任何相位假设**）：

```
S_剩 = S_全 − S_删   ⇒   |S_剩| ≥ |S_删| − |S_全|
  −80 dB：≥ 0.1381 − 0.0256 = 0.1125  →  不可能好于 −67.1 dB   （强制变差）
  −30 dB：≥ 8.0954 − 0.7753 = 7.3202  →  比 8.0954 小，允许变好  （实测确实变好）
```

对"负的比正的多"那一问的回答：−80 dB 时被删的 4 项之和是 `−0.0947 − 0.1005j`（实部为负），
而设计点总和是**正的** `+0.0256`；正减负 ⇒ 更正（`+0.1203`），长度从 0.0256 涨到 0.1567。
且只要 `|S_删| > |S_全|`，删正的一拨、删负的一拨**结果都是涨**。

## 5. 复查用的代码

```python
from pathlib import Path
import sys
import numpy as np

ROOT = Path(r"c:\Users\wuguo\Desktop\雷达抗ISRJ波形滤波器联合设计_PRD文档集")
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "参数搜索" / "scripts"))
import baseline
from isrj_joint_design.params import generate_isrj_sampling_function as G

DEPTH = -80.0
d = np.load(ROOT / "参数搜索" / "结果" / "设计对"
            / f"joint_design_v2_t0_2us_bmin{abs(DEPTH):g}dB.npz")
x, h = d["x"], d["h"]
D0 = baseline.TAU_US / baseline.TS_US
STEP = baseline.SAMPLE_US / baseline.TS_US

j0 = G(baseline.params_for(peak_interf_db=DEPTH))                             # 设计窗口
j1 = G(baseline.params_for(tau_us=(D0 - STEP) * baseline.TS_US,
                           peak_interf_db=DEPTH))                             # 变窄 1 个采样点
i0 = np.where(np.abs(j0) > 0.5)[0]
i1 = np.where(np.abs(j1) > 0.5)[0]
rm = np.setdiff1d(i0, i1)

S_full = (np.conj(h[i0]) * x[i0]).sum()
S_rm = (np.conj(h[rm]) * x[rm]).sum()
S_surv = (np.conj(h[i1]) * x[i1]).sum()
peak = abs(np.vdot(h, x))
for tag, v in (("S_full(60)", S_full), ("S_rm(4)", S_rm), ("S_surv(56)", S_surv)):
    print(f"{tag:12s} = {v.real:+.4f}{v.imag:+.4f}j   len={abs(v):.4f}"
          f"   {20 * np.log10(abs(v) / peak):+.2f} dB")
print("hard bound on S_surv:", abs(abs(S_rm) - abs(S_full)),
       "->", 20 * np.log10(abs(abs(S_rm) - abs(S_full)) / peak), "dB")
```
