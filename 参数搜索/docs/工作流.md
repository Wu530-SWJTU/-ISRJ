### W1 · 代价函数 C 定稿 + 谷形验证　✅ 已完成（2026-09-25，v2 口径）

**目标**：把汇报文档 §2.3 修正后的 C 落成代码，验出谷形（谷底、谷宽、是否多谷）
**做法**：C 复用 `compute_metrics` 的 `isrj_peak_db`（`C = 10^(isrj_peak_db/20)`）；用**固定设计对**
（录波口径）扫实际干扰参数，扫 `t_0`/`T_L`/`T_s` 三个维度与三对联合图
**产出**（均在 `参数搜索/结果/`）：
- 三对联合误差图 `联合误差/联合误差_三对总览.png`（t_0×T_s、t_0×T_L、T_L×T_s，**三对都是闭合谷**）
- 平滑性分析 `平滑性/平滑性分析_三维.png`
**门禁结论**：
- 谷底 −80.00 dB 精确落在设计点 ✓；两翼单调上升 ✓
- **谷宽只有 1 个采样点**（偏 0.1 μs 就抬升 47 dB）⇒ 搜索步长必须 ≤ 1 采样点
- ⚠️ **发现 3 个局部极小**（±0.5 μs 盒内）：整数采样下"移位 + 缩窗"能重新对齐采样支撑、凑出伪谷
- 量化台阶 1 采样点（99.5% 的细步长电平不变）
**对下游的影响**：W3 的"先测形状"已完成，且**多谷已确认**（不再是"退路"，而是必须处理的前提）

### W2 · WJPS 鲁棒设计　⛔ 待决策 2、4

**目标**：借鉴 Zhou 2026，把尖锐 V 型展宽为平缓 V 型（扩大可搜索范围）
**做法**：① 实现误差点族 `{j_m}` 的加权项（滤波器侧 `Σ_m ω_m [Toeplitz(r_h) ⊙ (j_m j_mᵀ)]`，波形侧 `Σ_m ω_m Toeplitz(r_{x⊙j_m})`）→ ② 单条约束 `x_j^H h = b_min` 推广为对每个误差点约束（`M_e+1` 约束 KKT）→ ③ 加"快速组装 vs 显式构造"等价性测试 → ④ 跑展宽前后对比
**产出**：新模块函数 + 测试；展宽前后 C 曲线对比图；`H_j`/`X_j` 矩阵链写入文档
**门禁**：两种组装数值等价；约束残差 < 1e-7；**谷底仍钉在 −30 dB**（不接受用谷底换展宽）
**退路**：约束不可行 / 条件数爆炸 → 改用加权松弛 `|x_{j,m}^H h| ≤ b_min`

---

### W3 · 搜索算法定标　⏳

**目标**：在 W1 已测得的形状上定标搜索算法（**形状已测，不再"先测再选"**）
**已知输入**（W1）：谷宽 1 采样点；三对闭合谷；**3 个局部极小**；`d` 维单点方向 30% 反向；量化台阶 0.1 μs
**做法**：① **粗网格全局扫**（步长 ≤ 1 采样点，`t_0`/`T_s` 各 ±0.5 μs ⇒ 11×11 = 121 点/对，防伪谷）→ ② 在主谷内用三分法 / 黄金分割精搜（步长 1 采样点）→ ③ 停止条件 `δ_θ`、`δ_C`、`K_max`、超时
**产出**：算法伪代码 + 成功率与评估次数统计表（含"落入伪谷"的失败率）
**门禁**：从 ±0.5 μs 初值收敛到 ±0.1 μs 内**且不落伪谷**；评估次数 < `K_max`
**退路**：伪谷比例过高 → 增大粗网格密度 / 用多起点
**术语**：不用「二分法」（那是求根），用「单峰极小搜索」

---

### W4 · 口径与算力校验　★ 全局瓶颈　⛔ 待决策 1、5

**目标**：量化「闭环口径 (c)」与「加速近似（固定 x + 模块三闭式 h）」的差异，决定搜索期用哪个
**做法**：同一段参数区间用两种口径各跑一遍，比较曲线偏差与单点耗时
**产出**：对比表（最大偏差 / 平均偏差 / 单点耗时）+ 口径选择结论
**门禁**：偏差可接受（如曲线最大偏差 < 1 dB）→ 搜索期用近似、交付曲线用闭环校验
**退路**：降规模 `N = 200/400`（保持 `N = B·T_p` 自洽）
**为什么是瓶颈**：v2 下一次完整设计 ≈ **5 s**（L=256，比 v1 快 10 倍）；三维 11×11×11 = 1331 点 ≈ **1.9 小时**（闭环口径）。录波口径（固定设计对）每次评估仅约**毫秒**，网格搜索秒级完成。

---

### W5 · 二维扩展 (T_s, d)　⛔ 待决策 3

**目标**：加入占空比维度，检验二维是否仍近似单峰、两维是否耦合
**做法**：坐标下降（先 T_s 后 d，交替）与二维网格对照（`T_L = d·T_s` 随动）
**产出**：二维 C 热图 + 收敛对比
**门禁**：二维网格显示单谷；坐标下降收敛到与网格一致的最优点
**退路**：强耦合导致停滞 → 二维粗网格 + 局部精搜索

---

### W6 · 三维扩展 (t_0, d, T_s)

**目标**：完整三维搜索，评估计算量、成功率、局部极小风险
**做法**：粗搜索 + 局部精搜索；核算算力预算
**产出**：三维结果 + 成功率统计 + 计算量报告
**门禁**：预算内成功率达标
**退路**：三维不可行 → 交付二维结果 + 三维可行性分析（本身即为结论）

## 五、风险与退路

| 风险 | 触发信号 | 退路 |
|---|---|---|
| C 曲线两翼非单调 | W1 门禁失败 | 分列零延迟与整体峰值，查旁瓣超越 |
| 展宽牺牲谷底 | 谷底 > −80 dB | 调权重/约束，不接受降谷底 |
| **搜索落入伪谷** | 收敛点 ≠ 主谷（`t_0` 偏 ±4 点、`T_L` 短 4 点附近） | 粗网格全局扫（≤1 采样点步长）+ 多起点；对比候选点的 C 值 |
| 评估噪声大 | 相邻点 C 跳变 | 固定内层迭代/热启动，重复取均值 |
| 闭环算力不可行 | 三维预算超限 | 加速近似 → 降规模 → 只做二维 |
| 权重方向性与实测不对称不匹配 | 展宽偏向错误一侧 | 按实测退化曲线定权，不照搬 `ω_m = m/Σm` |
| Zhou 2026 泛函不同（AF 能量 vs ISL/IL） | 迁移后指标不可比 | 只借鉴「多误差点加权」思想，权重与约束自行推导 |
