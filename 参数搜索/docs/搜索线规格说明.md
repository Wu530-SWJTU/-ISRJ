## 2. 已定稿口径（2026-09-12）

### 2.1 参数向量

```
θ = [t_0, d, T_s]^T        θ* 真实参数 ； θ̂ 候选参数
T_L = d · T_s              截取长度，派生量，不进搜索向量
```

搜索 `T_s` 时 **`T_L = d·T_s` 随动**（占空比恒定是干扰机的物理设定）。方向：截取长度↑ ⇒ 占空比↑。

**搜索线基线（v2，2026-09-25 用户确定，对齐 Zhou 等 2026 Signal Processing 245）**：

| 参数 | v2 基线值 | 采样点 | 说明 |
|---|---|---|---|
| `B` 带宽 | **10 MHz** | — | 论文 §4.1 |
| `T_p` 脉宽 | **25.6 μs** | — | 论文 §4.1 |
| `L` 码长（= `B·T_p`） | **256** | — | 论文 §4.1；本项目沿用符号 `N` |
| `fs` 复采样率 | **10 MHz** | 1 点 = **0.1 μs** | `fs = B` |
| `t_0` 窗口起点 | **2 μs** | 20 点 | **用户指定**（论文式(15)的原位窗从 0 开始） |
| `T_L` 截取长度 | **1.5 μs** | 15 点 | 论文 §4.1 |
| `T_s` 采样周期 | **6.4 μs** | 64 点 | 论文 §4.1 |
| `d` 占空比 | **0.234**（= `T_L/T_s`） | — | 派生量 |
| 码内采样片数 `K` | **4** | — | `L/(T_s·fs)`，与论文一致 |
| **干扰峰值约束** | **`b_min = b_max·10⁻⁴`（−80 dB）** | — | 论文 `a_min = a_max·10⁻⁴` |
| 参数误差范围 | **±0.5 μs**（三个误差同） | ±5 点 | 论文 Fig.12 |

四条决策（2026-09-25）：① 信号侧照搬论文 256 点体系；② 干扰侧照搬论文，**窗口起点改用
`t_0 = 2 μs`**；③ 峰值约束取 −80 dB；④ **保持零延迟原位模型**（不含论文的 `T_L` 延迟转发）。

**唯一参数来源：`参数搜索/scripts/baseline.py`**（各脚本一律从它取参数，禁止再散落硬编码）。
不继承论文的 ISAC 部分（通信波形 `s`、QPSK、多普勒区间、PAPR = 1.5 的通信约束），初始化仍用
`random_phase`；载频沿用 `f_c = 1 GHz`。

**v1（已归档）**：自建 800 点体系（`B = fs = 20 MHz`、`T_p = 40 μs`、`L = 800`、
`t_0 = 2.5 μs`、`T_L = 2.5 μs`、`T_s = 10 μs`、`d = 0.25`、约束 −30 dB），结果归档在
`参数搜索/结果/_v1_自建800点/`，仅作对照，不再更新。

有效范围：窗口不得跨周期，`t_0 + T_L <= T_s` ⇒ v2 下 `t_0 ∈ [0, 4.9] μs`（1.5 + 4.9 = 6.4）。

### 2.2 代价函数 C（核心）

```
        max_k | ( y_j(θ*) ∗ h(θ̂) )[k] |      ← 分子：真实干扰（接收数据）
C(θ̂) = ─────────────────────────────────
        max_k | (   x(θ̂)   ∗ h(θ̂) )[k] |      ← 分母：期望信号主峰 = b_max = N
```

- **分子必须含真实参数 θ\***。分子若写 `j(θ̂)`，会被设计约束 `x_j^H h = b_min` 钉死，`C(θ̂) ≡ b_min/b_max = 0.0316` 与 θ̂ 无关，搜索彻底失效（退化证明见《组会汇报》§2.3）。
- 分母 = `|h^H x| = b_max = N`，由硬约束钉死，**不是**自由量，不可被优化器压低。
- 换算：`C = 10^(isrj_peak_db / 20)`；报告中如用 dB 需注明是同一量的两种写法。

### 2.3 干扰模型

**转发时延 0、边采样边转发、单份原位**：

```
信号级： y_j(θ) = x ⊙ j(θ)
矩阵级： J(θ) = diag(j(θ))，  y_j(θ) = J(θ)·x
         H_j = H·diag(j(θ))
```

多份转发（`retransmit_offsets`）与论文图 4 的干扰机时延**不建模**。

### 2.4 评估口径

每个候选 θ̂ 都**重新联合设计** `(x(θ̂), h(θ̂))`。该口径对应**闭环自适应雷达**（估计 → 重设计 → 下次发射），不是"对同一段录波数据的处理"——报告中必须如此表述。录波口径（固定一对 (x,h) 处理同一段数据）作为对照实验，见 W4。

### 2.5 干信比（评估侧口径）

设计模型对干扰幅度**尺度不变**（约束 `x^H h = b_max`、`x_j^H h = b_min` 均为相对量），
所以 SJR 不影响任何计算，只决定"结果怎么读"。本项目口径（用户 2026-09-12 确定）：

```
目标回波   x            每个采样点 |x[n]| = 1
干扰信号   y_j = x ⊙ j   采样点上 |y_j[n]| = 1，其余为 0
⇒ 幅度口径  J/S = 0 dB   （干扰与回波同幅度，无额外缩放）
```

因此图中"归一化电平"可直接读作**假目标相对真目标的电平**：v2 谷底 −80 dB 就是
"假目标比真目标低 80 dB"，无需换算。

同一份数据的三种读法：

| 口径 | 值 | 来源 |
|---|---|---|
| **瞬时幅度（本项目口径）** | **0 dB** | 干扰与回波都是单位模 |
| 能量（整个码内） | −6.3 dB | 干扰只在约 1/4 采样点发射（占空比 0.234）→ 60/256 |
| 匹配滤波峰值 | −6.3 dB | 干扰匹配峰 Σ j[n]·|x[n]|² = 60，目标 = 256 |

⚠️ 两个易混点：
- 旧变量 `params.SJR_db = −10` 属论文图 4 场景（未实现），其值为**信干比 S/J**，与本口径符号相反；
- 改变 SJR 只是把电平曲线**整体平移**（形状不变）；要改误差容限必须动设计端。

### 2.6 符号表

以《组会汇报》附录 A 为准，摘要：`t_0`（转发起始时间）、`d`（占空比）、`T_L`（截取长度）、`T_s`（采样重复周期）、`x`/`h`（波形/滤波器，不用 `w`）、`j`（采样函数）、`J`（转移矩阵）、`y_j`（干扰信号，不用 `j(θ̂)`）、`M_e`（误差离散点数，不用 `M`）、`Δ`（误差范围，不用 `ε`）、`δ_θ`/`δ_C`（停止阈值，不用 `δ`）、`K_max`（评估次数上限，不用 `N_max`）。

```
W1 C 定稿 + 一维 V 型验证 → W2 WJPS 展宽 → W3 搜索算法定标
```

## 4. 工程约定

1. **分支**：搜索线占**一条长期分支 `参数搜索`**（不按实验族拆分支——W1–W6 依次依赖，交接频繁）。实验族分支的做法仅适用于复现线的误差评估。
2. **结果归档**：搜索线每族实验一个目录 `参数搜索/结果/<族>/`，内含 `joint_design_result_<init>.npz`、`<族>_sweep.json`、`结果表.md`、同名 `.png`。
3. **口径标注**：图与 JSON 必须标注设计初始化（`random_phase` / `lfm`）与评估口径（闭环 / 录波）。
4. **改代码必跑全量测试**：`.venv/Scripts/python.exe -m pytest tests/ -q`（Windows 下勿用裸 `python`）。
5. **干扰模型改动**：必须在回复与文档中同时给出信号级公式与 `H_j`/`X_j` 矩阵链，不能只给代码。
6. **未决不前推**：决策门未拍板前，不实现对应阶段的代码（尤其 W2 的 WJPS：权重与约束形式未定）。
7. **图标题措辞**：滤波/卷积输出用 `after filtering`（或 `through`），误差扫描写 `under <某> error`；
   **不用 `vs.`** ——本项目里 `A vs. filter` 已经是"经滤波器处理"的含义（复现线图 2），
   再用它表示"随某量变化"会误读。用户 2026-09-12 指出。
