## 1. 边界与依赖

### 1.1 复现线是依赖，不是工作区

搜索线**调用**下列冻结接口，但**不修改** `isrj_joint_design/`。确需修改时（例如给 `compute_metrics` 增字段）：改动必须向后兼容、跑全量测试、并在提交信息中写明理由。

| 模块 | 允许调用的接口 |
|---|---|
| `params` | `GlobalParams`、`generate_isrj_sampling_function`、`generate_isrj_jamming_signal`、`initialize_variables` |
| `matrices` | `assemble_P`、`assemble_Q`（快速组装）、`build_*`（显式构造，供等价性测试）、`cross_correlation`、`autocorrelation_matrix` |
| `filter_solver` | `solve_filter_lagrange`（滤波器闭式解）、`filter_constraint_residuals` |
| `waveform_admm` | `solve_waveform_admm` |
| `joint_design` | `compute_metrics`（指标，含 `isrj_peak_db`）、`joint_design_algorithm`（完整设计） |
| `plotting` | `plot_param_error_sweep`、`plot_param_error_result` 等 |
| `numerics` | `hermitian_cholesky`、`cho_solve_vec` |

### 1.2 搜索线产物放哪（独立项目文件夹）

搜索线的**全部产物**放在仓库根的 `参数搜索/` 下，与复现线（`isrj_joint_design/`、
`tests/`、`scripts/`、`参数误差/`）**物理分开**，便于单独查看与交付：

```
参数搜索/
├── README.md            项目说明、基线与运行入口
├── docs/                规格说明、组会汇报、工作流
├── scripts/             搜索线脚本（run_*.py）
└── 结果/<族>/           每族实验：设计对 npz + json + png + 结果表.md
```

- 包代码（C 计算入口、WJPS 组装、搜索算法）放 `参数搜索/` 下（如 `参数搜索/isrj_search/`），
  **W1 开工时创建**，不预建空包
- 脚本用 `sys.path` 引入复现线包，只调用 §1.1 的公开接口；复现线一行不改

## 2. 已定稿口径（2026-09-12）

### 2.1 参数向量

```
θ = [t_0, d, T_s]^T        θ* 真实参数 ； θ̂ 候选参数
T_L = d · T_s              截取长度，派生量，不进搜索向量
```

搜索 `T_s` 时 **`T_L = d·T_s` 随动**（占空比恒定是干扰机的物理设定）。方向：截取长度↑ ⇒ 占空比↑。

**搜索线基线（新项目默认口径，2026-09-12 用户确定）**：

| 参数 | 基线值 | 说明 |
|---|---|---|
| `t_0` | **2.5 μs** | 窗口 `[2.5, 5) μs`（复现线默认 0 μs） |
| `d` | 0.25 | 占空比 |
| `T_s` | 10 μs | 采样重复周期 |
| `T_L` | 2.5 μs | 截取长度（`= d·T_s`） |

基线由搜索线脚本**显式传入** `GlobalParams(tau_offset=2.5e-6, ...)`。**不改动**
`isrj_joint_design/params.py` 的默认 `tau_offset = 0.0`——那是 PRD 验收基线，
`tests/test_params.py::test_sampling_function_default_window_is_prd_baseline` 有断言。

有效范围：窗口不得跨周期，`t_0 + T_L <= T_s` ⇒ `t_0 ∈ [0, 7.5] μs`。

### 2.2 代价函数 C（核心）

```
        max_k | ( y_j(θ*) ∗ h(θ̂) )[k] |      ← 分子：真实干扰（接收数据）
C(θ̂) = ─────────────────────────────────
        max_k | (   x(θ̂)   ∗ h(θ̂) )[k] |      ← 分母：期望信号主峰 = b_max = N
```

- **分子必须含真实参数 θ\***。分子若写 `j(θ̂)`，会被设计约束 `x_j^H h = b_min` 钉死，`C(θ̂) ≡ b_min/b_max = 0.0316` 与 θ̂ 无关，搜索彻底失效（退化证明见《组会汇报》§2.3）。
- 分母 = `|h^H x| = b_max = N`，由硬约束钉死，**不是**自由量，不可被优化器压低。
- 换算：`C = 10^(isrj_peak_db / 20)`；报告中如用 dB 需注明是同一量的两种写法。

### 2.3 干扰模型

**转发时延 0、边采样边转发、单份原位**：

```
信号级： y_j(θ) = x ⊙ j(θ)
矩阵级： J(θ) = diag(j(θ))，  y_j(θ) = J(θ)·x
         H_j = H·diag(j(θ))
```

多份转发（`retransmit_offsets`）与论文图 4 的干扰机时延**不建模**。

### 2.4 评估口径

每个候选 θ̂ 都**重新联合设计** `(x(θ̂), h(θ̂))`。该口径对应**闭环自适应雷达**（估计 → 重设计 → 下次发射），不是"对同一段录波数据的处理"——报告中必须如此表述。录波口径（固定一对 (x,h) 处理同一段数据）作为对照实验，见 W4。

### 2.5 符号表

以《组会汇报》附录 A 为准，摘要：`t_0`（转发起始时间）、`d`（占空比）、`T_L`（截取长度）、`T_s`（采样重复周期）、`x`/`h`（波形/滤波器，不用 `w`）、`j`（采样函数）、`J`（转移矩阵）、`y_j`（干扰信号，不用 `j(θ̂)`）、`M_e`（误差离散点数，不用 `M`）、`Δ`（误差范围，不用 `ε`）、`δ_θ`/`δ_C`（停止阈值，不用 `δ`）、`K_max`（评估次数上限，不用 `N_max`）。

## 3. 阶段与门禁

见《工作流》（`工作流.md`）§二、§三。要点：

```
W1 C 定稿 + 一维 V 型验证 → W2 WJPS 展宽 → W3 搜索算法定标
   → W4 口径与算力校验（★瓶颈）→ W5 二维 → W6 三维
```

**5 个决策门**（未拍板前不得进入对应阶段）：

| # | 决策 | 阻塞 |
|---|---|---|
| 1 | 闭环口径是否可接受 / 是否需录波对照 | W4 |
| 2 | 内层设计沿用交替优化还是跟进 AJO-MM | W2 |
| 3 | 是否先只做一维 | W5、W6 |
| 4 | WJPS 的 `ω_m` / `Δ` / `M_e`（权重公式需对照 Zhou 2026 原文核实） | W2 |
| 5 | 搜索期是否引入加速近似 | W4 |

## 4. 工程约定

1. **分支**：搜索线占**一条长期分支 `参数搜索`**（不按实验族拆分支——W1–W6 依次依赖，交接频繁）。实验族分支的做法仅适用于复现线的误差评估。
2. **结果归档**：搜索线每族实验一个目录 `参数搜索/结果/<族>/`，内含 `joint_design_result_<init>.npz`、`<族>_sweep.json`、`结果表.md`、同名 `.png`。
3. **口径标注**：图与 JSON 必须标注设计初始化（`random_phase` / `lfm`）与评估口径（闭环 / 录波）。
4. **改代码必跑全量测试**：`.venv/Scripts/python.exe -m pytest tests/ -q`（Windows 下勿用裸 `python`）。
5. **干扰模型改动**：必须在回复与文档中同时给出信号级公式与 `H_j`/`X_j` 矩阵链，不能只给代码。
6. **未决不前推**：决策门未拍板前，不实现对应阶段的代码（尤其 W2 的 WJPS：权重与约束形式未定）。
7. **图标题措辞**：滤波/卷积输出用 `after filtering`（或 `through`），误差扫描写 `under <某> error`；
   **不用 `vs.`** ——本项目里 `A vs. filter` 已经是"经滤波器处理"的含义（复现线图 2），
   再用它表示"随某量变化"会误读。用户 2026-09-12 指出。
