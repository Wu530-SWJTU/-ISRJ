# 码内采样窗口数对比（占空比固定 0.25，T_L = 0.25·T_s 随 T_s 缩放）

扫描 ε ∈ ±1.25 μs（步长 0.05 μs = 1 个采样点）；t_0 基线 = T_s/4。K=4：T_s = 10 μs / T_L = 2.5 μs；K=8：T_s = 5 μs / T_L = 1.25 μs。

|---|---|---|---|---|---|---|---|---|---|
