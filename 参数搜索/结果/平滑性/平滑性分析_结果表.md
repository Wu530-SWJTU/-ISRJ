# 三维平滑性分析（θ = [t_0, d, T_s]）

固定设计对 `joint_design_result_t0_2.5us.npz`；1 采样点 = 0.05 μs（d 步长 0.005）。

| 项目 | 结果 |
|---|---|
| 量化台阶（t_0） | 零差分步长占 99.5%，跳变 2 次 ⇒ 分辨率 = 1 采样点 |
| 量化台阶（T_s） | 零差分占 99.5%，跳变 2 次 |
| 量化台阶（d） | 零差分占 99.5%，跳变 2 次 |
| 曲率 t_0 | 中位数 -0.228 dB/点²（|最大| 1.332） |
| 曲率 T_s | 中位数 -0.328 dB/点²（|最大| 0.801） |
| 曲率 d | 中位数 -0.281 dB/点²（|最大| 1.104） |
| 局部极小（11³ 网格） | **0 个**（全局最小 -39.48 dB） |
| 微粗糙度（1 点步长） | t_0 符号翻转 1/40 ; T_s 符号翻转 1/40 ; d 符号翻转 10/40 |
| 单边斜率 @设计点 | t_0: +1点 +1.80 / -1点 +1.62 dB ; T_s: +1点 +1.76 / -1点 -0.27 dB ; d: +1点 +2.60 / -1点 +2.49 dB |
| 设计点 Hessian 特征值 | +1.1964 , +3.2499 , +5.5547 dB/点² |
| 设计点性质 | 位移型维度上是 $|\cdot|$ 型拐点（C0 但不 C1），±1 点处 -28.20 / -28.38 dB |

## 结论

1. **分辨率下限 = 1 采样点**：细扫中 99.5% 的步长电平不变（分段常数），只在整数采样边界跳变 ⇒ 小于 0.05 μs（d 为 0.005）的步长无法产生任何梯度。
2. **采样点尺度以上光滑**：二阶差分中位数 0.23–0.33 dB/点²、|最大| ≤ 1.33 dB/点²，曲率有界、无奇异。
3. **1 采样点尺度存在微粗糙度**：增量符号翻转比例 t_0 1/40、T_s 1/40（干净），但 **d 高达 10/40 = 25%**——`d` 方向在单样本尺度上是「噪声状」的，其单调趋势只是统计平均。
4. **三维网格内无严格局部极小**：`d` 维单调把谷底推成一条通向边界的槽（全局最小 −39.48 dB 落在 d = −0.10 边界上）。
5. **设计点是拐点**：位移型维度上是 $|\cdot|$ 型（C0 但不 C1），中心差分 Hessian 会给出全正特征值、把单调方向误判为局部极小，须同时看单边斜率。

**对搜索算法的直接含义**：① 步长必须 ≥ 1 采样点，有限差分梯度步长同样如此；② `d` 维不要用单样本步长的爬山/坐标下降（25% 的步长方向是错的），要么粗步长、要么平滑（对若干样本取平均）；③ `t_0`、`T_s` 两维可直接用基于梯度的搜索。
