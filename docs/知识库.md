## 1. ISRJ 原理（领域背景）

ISRJ（中断采样转发干扰）干扰机的工作方式：**周期性开窗截取**雷达发射波形（周期 T_s、
窗口 tau，典型占空比 0.25），再把采到的切片转发出去。它对雷达的威胁在于：采样切片是
真实波形的一部分，与雷达发射波形天然相参，脉压后会形成**一串高度逼真的假目标**，且
重复转发可进一步加密假目标串。对抗思路（本论文）：不再用匹配滤波器（假目标就在匹配
滤波器主瓣里），而是联合设计**发射波形 x 与失配滤波器 h**——滤波器专门"挖坑"压低
ISRJ 输出，同时保持主瓣增益（b_max 约束）和可接受的旁瓣（ISLs）与干扰电平（ILs）。

## 2. 论文模型（式 1–16 的物理解释）

| 公式 | 内容 | 物理意义 |
|------|------|----------|
| (1)–(5) | H、X、H_j、X_j 矩阵 | 脉压输出 r=Hx（=共轭意义下的 Xh）与干扰输出 r_j=H_jx 的矩阵表达 |
| (6) | 目标函数 | `min x^H P x`（或 `h^H Q h`）= ε·ISLs + (1−ε)·ILs，Pareto 权重 ε 平衡旁瓣与干扰 |
| 约束 | h^H x=b_max、h_j^H x=b_min | 主瓣峰值钉在 N；干扰零延迟输出钉在 −30 dB（b_min=N·10^(−1.5)） |
| 约束 | PAPR ≤ η | 波形峰均比限制（η=1 恒模），改写为 x^H x=N 与 \|x[n]\|²≤η |
| (7)–(8) | 滤波器闭式解 | 固定 x 时是凸二次规划，拉格朗日乘子法闭式解（含勘误，见 §3.2） |
| (9)–(16) | ADMM 波形求解 | 固定 h 时因球面约束非凸，引入 y（能量）、z（PAPR）解耦，四个子步骤全闭式 |

交替优化（Algorithm 1）：外层 M=100 轮，每轮先解 h（闭式）再解 x（ADMM），辅助/对偶
变量热启动。

## 3. 推导成果（本项目的贡献点）

### 3.1 矩阵共轭约定（ADR-0001）

PRD 图示（无共轭）与验收 2（峰值 = h^H x）互斥，因为 `Hx` 关于 h 共轭线性、`Xh` 关于
h 线性。取带共轭：`H[k,n]=conj(h[k−N+n])`、`X[k,n]=conj(x[N+n−k])`，则
`(Hx)[N]=h^H x` 精确成立、`Hx=conj(Xh)`；D 为实对角阵保证 `x^H P x == h^H Q h` 严格成立。

### 3.2 式(8) 勘误（ADR-0002）

双线性等式约束二次规划的解析解必为 `Q^{-1}x` 与 `Q^{-1}x_j` 的**两项线性组合**；论文
印刷版漏第二项且第二项系数漏共轭。正确形式：

```
h = (1/D)[(b_max·c − b_min·b)·Q^{-1}x + (b_min·a − b_max·b*)·Q^{-1}x_j]
D = a·c − |b|²,  a=x^H Q^{-1}x,  b=x^H Q^{-1}x_j,  c=x_j^H Q^{-1}x_j
```

验证：用 b*（非 b）代回约束才得 `b_max(ac−|b|²)/D = b_max` ✓。已用独立 KKT 线性方程组
解法交叉验证（`test_matches_kkt_linear_system_solution`）。

### 3.3 Toeplitz 快速组装（决策 #3）

避开展开 (2N−1)×N 大矩阵：`H^H D H = Toeplitz(r_h) − h h^H`（r_h 为 h 的自相关，FFT
计算），`H_j^H H_j = diag(j)·Toeplitz(r_h)·diag(j)`；`X_j^H X_j` 是 `x⊙j` 的自相关
Toeplitz 阵（**不是** `diag(j)X^H X diag(j)`，因为 X_j 由翻转的 x⊙j 铺成）。显式构造
保留并与快速路径测试等价（等价性被测试锁定，防回归）。

### 3.4 ADMM 系数 A=2P+2ρI+ρhh^H+ρh_jh_j^H（决策 #4）

把复数 x 拆实虚部、对实向量求导的结果是 2P（用 P 是错的）；h、h_j 秩-1 修正项对应两条
等式约束的增广项。A 在内层迭代中不变 → Cholesky 分解一次、反复回代。

### 3.5 处理增益损失的上界（ADR-0003 的核心推导）

主瓣被钉在 N 时：`loss = 10log10(N²/(||h||²·N)) = 10log10(N/||h||²)`——损失完全由滤波
器能量决定（失配滤波器放大噪声：输出噪声 ||h||²σ² vs 匹配滤波 Nσ²）。两条峰值约束把 h
钉在二维仿射子空间 {x, x_j} 内，该子空间的最小范数点（伪逆解）给出**理论上界**：实测
η=1.1 时 −0.77 dB、随 PAPR 单调改善（η=1.44 时 −0.14 dB）。任何旁瓣/干扰抑制要求都使
||h||² 增大，损失变差。

### 3.6 双转发干扰的平移性质（评估侧实现的理论依据）

零时延多转发的干扰信号 `y_jam = Σ_r shift_{d_r}(x⊙j)` 是 x 的线性算子
`J_multi = (I+S_{d_1}+…)·diag(j)`。互相关的平移不变性给出**关键性质**：

```
r_multi = Σ_r shift_{d_r}(r_j)，其中 r_j = 单份干扰的脉压输出
```

即第二份转发的输出 = 第一份输出整体平移 d_1。因此：第二份的主瓣（−30 dB 那根）跟着平
移，落在主瓣位置的则是已被 ILs 目标压到 −30 dB 以下的旁瓣——**单份模型设计的滤波器对
"主瓣仍钉在零延迟"的多转发天然免疫**（边采样边转发模型实测峰值 −30.49 dB，能量比
1.984 ≈ 2 纯叠加）。**但若转发带时延（如转发#1 偏移 2.5 μs）**，主瓣整体移出零延迟
约束位，"免疫"失效：单份输出的旁瓣结构不对称（负向滞后 −50 点处约 −32 dB，正向滞后
均 < −46 dB），时延把这些强旁瓣搬进零延迟区，峰值升至 −28.88 dB（超限 1.12 dB）——
见 §4。

### 3.7 ADMM 不可行性判据（决策 #8）

|h^H x| ≤ ||h||·||x|| = N（随机单位模 h）取等要求 x=h，此时 `h_j^H x` = j 的非零个数
≠ b_min → 约束集为空，ADMM 停在残差最小点不收敛。判据：**ADMM 必须接拉格朗日解出的
h**（其范数不受限、专门迁就当前 x 满足两条约束），且 x 的初值已满足等式约束。

## 4. 数值实验结论库

| 现象/问题 | 实验 | 结论 |
|-----------|------|------|
| 损失差 1.6 dB 从哪来 | ε 探测、min-norm 上界、种子/LFM 对照 | 旁瓣抑制代价 + 非凸盆地选择；非数值误差（ADR-0003） |
| 图 3(a) 趋势为何不成立 | random_phase 与 lfm 各 4 起点扫描 | 随机相位盆损失 −2.5±0.3 dB 无单调性；LFM 盆 −1.32→−0.50 dB 单调（起点极差 0.01–0.08 dB） |
| 占空比的影响 | 窗口 [0.25, 0.5) μs（2.5%）vs [0, 2.5) μs（25%） | 占空比决定设计难度：干扰越稀，PSL 越深（−31.6→−41.4 dB）、损失代价越大（−2.49→−3.05 dB） |
| 窗口位置的影响 | [2.5, 5) μs vs [0, 2.5) μs（同占空比） | 指标在种子波动内（零结果）；位置只影响 ADMM 条件数（耗时 58→120 s） |
| 双转发是否破坏抑制 | T_s=20μs、偏移 (0, 10μs) 评估 | 峰值 −30.49 dB 仍达标；能量 ≈2×；平移性质 §3.6 |
| 转发时延的影响 | 转发#1 偏移 0 → 2.5 μs（offs (2.5, 10)μs） | 峰值 −30.49 → **−28.88 dB（相对无误差基准退化 1.12 dB）**：主瓣移出约束位，负向滞后强旁瓣进入零延迟区；设计只对"零延迟单份"几何免疫 |
| 内层 ADMM 首轮不收敛 | 预热现象观测 | 前 1–2 轮触顶 500 次（~1e-3），热启动建立后每轮 < 1e-4（决策 #9） |
