**三句话读懂整个计划**：

1. 先把「猜错参数会变差」这件事量化成一个数 **C**，并验证 C 的曲线是 **V 型**（谷底 = 真实参数）。
2. 再用 **WJPS 把 V 型谷口展宽**，让搜索有路可走。
3. 最后设计**搜索算法**在一维、二维、三维上把谷底找出来。

### W1 · 代价函数 C 定稿 + 一维 V 型验证　⏳

**目标**：把汇报文档 §2.3 修正后的 C 落成代码，复现 V 型（含不对称性）
**做法**：① 实现 `C = max|y_j(θ*)∗h| / max|x∗h|` 统一入口（复用 `isrj_peak_db`，`C = 10^(isrj_peak_db/20)`）→ ② 扫描脚本增加 `C` 字段 → ③ 画 C(ΔT_s) 并检查单峰/单调
**产出**：C 曲线图 + 含 `C` 的 JSON
**门禁**：谷底落在无误差处且 ≈ 0.0316；两翼单调上升；换算关系有单测
**退路**：某翼非单调 → 分列「零延迟电平」与「整体峰值」，查旁瓣是否超越零延迟
**复用**：`run_ts_error_sweep.py`、`compute_metrics`、`plot_param_error_sweep`

---

### W2 · WJPS 鲁棒设计　⛔ 待决策 2、4

**目标**：借鉴 Zhou 2026，把尖锐 V 型展宽为平缓 V 型（扩大可搜索范围）
**做法**：① 实现误差点族 `{j_m}` 的加权项（滤波器侧 `Σ_m ω_m [Toeplitz(r_h) ⊙ (j_m j_mᵀ)]`，波形侧 `Σ_m ω_m Toeplitz(r_{x⊙j_m})`）→ ② 单条约束 `x_j^H h = b_min` 推广为对每个误差点约束（`M_e+1` 约束 KKT）→ ③ 加"快速组装 vs 显式构造"等价性测试 → ④ 跑展宽前后对比
**产出**：新模块函数 + 测试；展宽前后 C 曲线对比图；`H_j`/`X_j` 矩阵链写入文档
**门禁**：两种组装数值等价；约束残差 < 1e-7；**谷底仍钉在 −30 dB**（不接受用谷底换展宽）
**退路**：约束不可行 / 条件数爆炸 → 改用加权松弛 `|x_{j,m}^H h| ≤ b_min`

---

### W3 · 搜索算法定标　⏳

**目标**：**先实测曲线形状，再选算法**（顺序不能反）
**做法**：① 粗网格实测：单峰性、谷宽、评估噪声（相邻点 C 差值是否被内层收敛差异污染）→ ② 据此选三分法 / 黄金分割 / 抛物线拟合 → ③ 实现停止条件 `δ_θ`（区间宽度）、`δ_C`（改善量）、`K_max`（评估次数）、超时
**产出**：算法伪代码 + 成功率与评估次数统计表
**门禁**：从 ±0.5 μs 初值收敛到 ±0.1 μs 内；评估次数 < `K_max`
**退路**：出现多谷 → 粗网格定位 + 局部精搜索
**术语**：不用「二分法」（那是求根），用「单峰极小搜索」

---

### W4 · 口径与算力校验　★ 全局瓶颈　⛔ 待决策 1、5

**目标**：量化「闭环口径 (c)」与「加速近似（固定 x + 模块三闭式 h）」的差异，决定搜索期用哪个
**做法**：同一段参数区间用两种口径各跑一遍，比较曲线偏差与单点耗时
**产出**：对比表（最大偏差 / 平均偏差 / 单点耗时）+ 口径选择结论
**门禁**：偏差可接受（如曲线最大偏差 < 1 dB）→ 搜索期用近似、交付曲线用闭环校验
**退路**：降规模 `N = 200/400`（保持 `N = B·T_p` 自洽）
**为什么是瓶颈**：全规模一次完整设计 ≈ 1 min；三维 21×11×11 = 2541 点 ≈ 40+ 小时。**近似可用，W5/W6 才现实。**

---

### W5 · 二维扩展 (T_s, d)　⛔ 待决策 3

**目标**：加入占空比维度，检验二维是否仍近似单峰、两维是否耦合
**做法**：坐标下降（先 T_s 后 d，交替）与二维网格对照（`T_L = d·T_s` 随动）
**产出**：二维 C 热图 + 收敛对比
**门禁**：二维网格显示单谷；坐标下降收敛到与网格一致的最优点
**退路**：强耦合导致停滞 → 二维粗网格 + 局部精搜索

---

### W6 · 三维扩展 (t_0, d, T_s)

**目标**：完整三维搜索，评估计算量、成功率、局部极小风险
**做法**：粗搜索 + 局部精搜索；核算算力预算
**产出**：三维结果 + 成功率统计 + 计算量报告
**门禁**：预算内成功率达标
**退路**：三维不可行 → 交付二维结果 + 三维可行性分析（本身即为结论）

## 五、风险与退路

| 风险 | 触发信号 | 退路 |
|---|---|---|
| C 曲线两翼非单调 | W1 门禁失败 | 分列零延迟与整体峰值，查旁瓣超越 |
| 展宽牺牲谷底 | 谷底 > −30 dB | 调权重/约束，不接受降谷底 |
| 评估噪声大 | 相邻点 C 跳变 | 固定内层迭代/热启动，重复取均值 |
| 闭环算力不可行 | 三维预算超限 | 加速近似 → 降规模 → 只做二维 |
| 权重方向性与实测不对称不匹配 | 展宽偏向错误一侧 | 按实测退化曲线定权，不照搬 `ω_m = m/Σm` |
| Zhou 2026 泛函不同（AF 能量 vs ISL/IL） | 迁移后指标不可比 | 只借鉴「多误差点加权」思想，权重与约束自行推导 |

### 产物与命名规范（沿用现有惯例）

- 每族实验一个目录：`参数误差/<族>/`（如 `采样周期/`、`联合误差/`）
- 数值记录：`joint_design_result_<init>.npz`、`<族>_sweep.json`、`结果表.md`
- 图与 JSON 同名同目录；**图与 JSON 必须标注**：设计初始化（`random_phase`/`lfm`）、评估口径（闭环/固定对）
- 改代码先跑全量测试再提交；实验族各占一个 git 分支
- **改干扰模型**：回复与文档中必须同时给出信号级公式与 `H_j`/`X_j` 矩阵链
