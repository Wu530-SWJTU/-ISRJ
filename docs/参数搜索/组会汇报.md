## 1. 研究背景

间歇采样转发干扰（ISRJ）通过采样并转发雷达信号形成假目标。**已知** ISRJ 参数时，联合优化发射波形与接收滤波器可获得良好抗干扰性能（本项目已复现 Zhou 等 2020 IEEE SPL 的结果：主瓣/干扰约束残差 < 1e-7、PSL < −20 dB、零延迟干扰电平钉在 −30.00 dB）。

但实际电子对抗中，转发起始时间、占空比、采样周期等参数**未知或先验不准**，参数估计误差会显著恶化抗干扰效果。因此，如何快速、准确地估计 ISRJ 参数，是提升抗干扰性能的关键。

## 2. 问题描述与符号定义

### 2.1 干扰参数与信号模型

真实干扰参数与候选（假设）参数：

```
θ*  = [t_0*, d*, T_s*]^T      （真实参数，决定接收到的干扰）
θ̂  = [t_0 , d , T_s ]^T      （候选参数，决定设计所用的干扰模型）
```

| 符号 | 含义 | 本项目默认值 |
|---|---|---|
| `t_0` | **转发起始时间** = 采样起始时间（转发时延为 0，边采样边转发） | 0（窗口 `[0, T_L)`） |
| `d` | **占空比** | 0.25 |
| `T_s` | **采样重复周期** | 10 μs |
| `T_L` | 截取长度（采样时间长度），**派生量** `T_L = d·T_s` | 2.5 μs |

雷达侧参数：码长 `N = 800`、带宽 `B = 20 MHz`、脉宽 `T_p = 40 μs`、复采样率 `f_s = B`。

**采样函数**（0/1 向量，离散索引以采样点数计）：

```
N_Ts = round(T_s·f_s),  N_t0 = round(t_0·f_s),  N_TL = round(T_L·f_s)
j(θ)[n] = 1  ⟺  mod(n, N_Ts) ∈ [N_t0, N_t0 + N_TL)
```

**干扰信号**（边采样边转发，转发时延 0，单份原位）：

```
信号级:   y_j(θ) = x ⊙ j(θ)
矩阵级:   J(θ) = diag(j(θ)),    y_j(θ) = J(θ)·x
```

`J(θ)` 即 ISRJ 转移矩阵。默认参数下 `j` 周期 200 点、脉宽 50 点（占空比 0.25）。按约定，此处给出 `H_j` 的构造：设计阶段 `H_j = H·diag(j)`，`H` 为滤波器卷积矩阵（`(Hx)[N-1] = h^H x`）。

### 2.2 内层：给定 θ̂ 的波形–滤波器联合设计（oracle）

内层是一个黑箱：输入参数假设 θ̂，输出一对 `(x(θ̂), h(θ̂))`。本项目采用**交替优化**（Zhou 2020 Algorithm 1）：

- **固定波形 x，解滤波器 h**：带两条双线性等式约束的凸 QP

  ```
  min_h  h^H Q h    s.t.  x^H h = b_max,   x_j(θ̂)^H h = b_min
  ```

  由拉格朗日乘子法得闭式解（`Q^{-1}x` 与 `Q^{-1}x_j` 的两项线性组合，第二项系数含共轭）。

- **固定滤波器 h，解波形 x**：ADMM，至内层收敛判据 `‖x−y‖₂ + ‖x−z‖₂ < δ`。

- 两者交替，至外层最大轮数 `M` 或收敛。

其中 `b_max = N`、`b_min = N·10^(−30/20)`——主瓣峰值与零延迟干扰电平的硬约束。

> **注（Zhou 2026 的差异）**：Zhou 等 2026 针对 ISAC 场景提出了更复杂的 AJO-MM（交替联合优化 + 主化最小化），面向**模糊函数（AF）能量**抑制并附加通信波形相似性约束。其适配成本待评估（§6.4）。

### 2.3 代价函数 C —— 本版核心修正

**定义（修正后）**：

```
        max_k | ( y_j(θ*) ∗ h(θ̂) )[k] |          ← 真实干扰（接收数据）经候选滤波器
C(θ̂) = ────────────────────────────────────
        max_k | (   x(θ̂)   ∗ h(θ̂) )[k] |          ← 期望信号经同一滤波器的主峰
```

`C` 是一个**无量纲比值**：分子是干扰在滤波器输出上剩下的最高那根尖峰（假目标高度），分母是真实目标的主瓣高度。

- `C ≈ 1`：假目标与真目标一样高，抗干扰完全失效；
- `C = 0.0316`（= −30 dB）：假目标比真目标低 30 dB，即设计基准。

**本项目里这个量已经存在**：`isrj_peak_db = 20lg( max|r_j| / |h^H x| )`，故 `C = 10^(isrj_peak_db / 20)`。分母 `max_k |(x ∗ h)[k]| = |h^H x| = b_max = N`（由硬约束钉死，实测 799.9999996，残差 < 1e-7）——**分母是常数、解析已知，优化器无法把它压低来"刷低"C**。

#### 为什么分子必须是真实干扰（原写法的退化）

原稿写作 `j(θ̂)`，分子分母都只含 θ̂，**整个式子里没有 θ\***。此时：

- 设计约束 `x_j^H h = b_min` 把"假设参数下的干扰"在零延迟处钉死在 `b_min`；
- 其余延迟由 ILs 目标压低，实测 `max_k` 恰好落在零延迟处；

于是 `C(θ̂) ≈ b_min / b_max = 10^(−1.5) = 0.0316` 对**任意** θ̂ 成立——曲线是水平线，`argmin` 无定义，搜索无从下手。这不是数值问题，是定义问题：式子里没有任何东西能区分候选好坏。

**类比**：原写法相当于"每把钥匙都配一把刚好能被它插进去的锁"，当然把把匹配；正确写法是"同一把锁（接收数据，内含 θ\*）试所有钥匙"，只有对的才开。

#### 数值例（用已有实测数据）

真实参数 `T_s* = 10 μs`，用设计假设 `T_s = 10 μs` 的固定设计对处理实际干扰（数据来源：本项目"采样周期误差"实验，±0.1–±1.0 μs 共 21 点）：

| 实际周期 (μs) | 干扰输出峰值 (dB) | **C** |
|---|---|---|
| 9.0 (−1.0) | −10.72 | 0.291 |
| 9.6 (−0.4) | −16.33 | 0.153 |
| 9.8 (−0.2) | −21.31 | 0.086 |
| **10.0（无误差）** | **−30.00** | **0.0316** ← 最低 |
| 10.2 (+0.2) | −23.66 | 0.066 |
| 10.4 (+0.4) | −20.13 | 0.099 |
| 11.0 (+1.0) | −14.05 | 0.198 |

只有把真实干扰放进分子，C 才在 θ\* 处取得唯一最低点——这就是 V 型，也是"参数搜索"唯一可能成立的形式。

### 2.4 搜索目标

```
θ̂* = arg min_{θ̂} C(θ̂)   →   逼近 θ*
```

**评估口径（本轮确定）**：每个候选 θ̂ 都**重新联合设计** `(x(θ̂), h(θ̂))`。此时"真实干扰"是干扰机采样了本次发射的 `x(θ̂)` 再转发的结果，故各候选对应的接收数据并不完全相同——该口径对应**闭环自适应雷达**（估计 → 重设计 → 下次发射），不是"对同一段录波数据的处理"。这一点须在报告中写明（§6.1）。

## 3. 与 Zhou 2026 的关系

Zhou 等 2026（*Complementary ISAC waveform and filter design based on minimized AF sidelobes against ISRJ*, Signal Processing Vol. 245）针对 ISRJ 认知参数误差提出 **WJPS 加权联合处理策略**：

1. 设采样时间长度 `T_L` 的估计误差在 `[−Δ, Δ]` 内；
2. 将误差范围离散为 `M_e` 个点；
3. 对不同误差对应的干扰信号施加权重 `ω_m`，**误差越大权重越大**；
4. 在波形–滤波器联合优化中同时抑制误差范围内所有干扰信号，提升对参数误差的鲁棒性。

**它解决"参数不准时仍能抗干扰"，未解决"如何反向搜索更精确的参数"。**

本工作的切入点是：把鲁棒波形–滤波器联合设计当作**代价函数构造工具**，在其引导下反向搜索 ISRJ 参数。

> **待核实（重要）**：`ω_m = m / Σ_{m=1}^{M_e} m` 这一具体权重公式**未能从公开信息核实**；且原文 WJPS 压制的是**模糊函数能量**，与本项目的 ISL/IL 二次型不是同一个泛函。迁移时的权重设计、误差范围与离散点数需重新推导并对照原文。

## 4. 核心思路：V 型代价曲线 + WJPS 展宽

**已有观察**：在采样周期误差维度，归一化干扰电平随误差增大而升高，整体呈 **V 型**。实测（同上数据源）：

- 谷底在无误差处，被约束钉死为 **−30.00 dB**；
- **不对称**：负误差侧退化更快（−1.0 μs → −10.72 dB 退化 19.3 dB；+1.0 μs → −14.05 dB 退化 16.0 dB）；
- 谷底附近斜率健康：**0.1 μs ↔ 4–5 dB**（±0.1 μs 对应 −25.18 / −26.25 dB）。

若 V 型谷开口足够宽且底部平缓，初始估计即使不准也可通过搜索找到谷底；若谷过于尖锐，小误差即导致 C 急剧上升，搜索方向难以判断。因此拟借鉴 Zhou 2026 的 WJPS 思想，**把尖锐 V 型展宽为平缓 V 型**，扩大可搜索范围，再设计搜索算法逐步逼近谷底。

## 5. 研究内容与技术路线

整体路线：

```
干扰建模 → 代价函数定义 → 一维 V 型验证 → WJPS 鲁棒联合设计
        → 单峰区间收缩 → 二维扩展 → 三维联合搜索
```

### 5.1 一维采样周期搜索

固定 `d` 与 `t_0`，只搜索 `T_s`（`T_L = d·T_s` 随动，占空比恒定）。流程：

1. 在初始 `T̂_s` 附近，用 WJPS 思想设计鲁棒波形与滤波器；
2. 粗网格扫描定位谷区；
3. **单峰极小搜索**收缩区间（比较两点值 → 舍去一段 → 迭代）：
   - 若左点更低，极小在左区间；
   - 若右点更低，极小在右区间。

**术语纠正**：二分法（bisection）是**求根**方法，要求导数符号变化；单峰极小对应**三分法 / 黄金分割**（黄金分割每轮少一次评估）。

**停止条件**：

- 参数区间宽度 `< δ_θ`；
- `C` 改善量 `< δ_C`；
- 评估次数 `> K_max`；
- 超过最大搜索时间。

### 5.2 二维扩展

在一维成功基础上加入占空比维度 `d`。可采用坐标下降：先搜 `T_s`，再搜 `d`，交替进行。需分析两个维度是否耦合、是否仍近似单峰。

### 5.3 三维联合搜索

最后加入转发起始时间 `t_0`，形成三维搜索。评估计算量、搜索成功率、局部极小风险；必要时采用粗搜索 + 局部精搜索。

### 5.4 搜索策略分类

- **粗搜索**：完全不知道参数时，大范围网格扫描，定位 V 型谷区域；
- **精搜索**：已知参数大概位置时，小范围区间收缩。

整体流程：先粗后精。

## 6. 关键风险与待验证问题

### 6.1 评估口径：闭环 vs 录波（需导师确认）

本轮确定每个候选重设计 `(x, h)`（闭环口径）。其代价是：曲线比较的是"每个假设下各自最优的一对"，且每个候选对应的接收数据由不同的 `x(θ̂)` 生成。**物理上对应"估计 → 重设计 → 下次发射"的闭环雷达**，不是对同一段录波数据的处理。若需"固定一对处理链、处理同一段数据"的录波口径，C 变为只随实际误差变化（即 §2.3 数值例的口径），两者结论可能不同，须在报告中区分标注。

### 6.2 计算量（最硬的约束）

全规模 `N = 800` 一次完整联合设计约 **1 分钟**。闭环口径下每个候选都要跑一次：

- 一维 21 点扫描 ≈ 20+ 分钟；
- 三维 21×11×11 = 2541 点 ≈ **40+ 小时**（不可行）。

**候选出路**：
1. **加速近似**：搜索阶段固定波形 `x`、滤波器 `h(θ̂)` 用模块三**闭式解**逐候选重算（毫秒级），最终交付曲线用闭环口径校验；
2. 降规模做（`N = 200`，单次数秒）；
3. 纯闭环但只做一维、粗网格，接受时长。

**需先测定**：加速近似与闭环口径的曲线差多少（决定近似能否使用）。

### 6.3 搜索算法未定（依赖曲线形状）

C(θ̂) 的真实形状（是否单峰、谷宽、评估噪声）尚未实测，故三分法/黄金分割/抛物线拟合均未定。**先测形状，再选算法**。评估噪声的主要来源：相邻候选的 C 差值可能被内层优化的收敛差异污染，需固定迭代次数/热启动策略来压制。

### 6.4 内层设计方法待考究

本项目沿用 Zhou 2020 的交替优化（h 闭式解 + x ADMM），已实现且通过验收；Zhou 2026 的 AJO-MM 面向 AF 能量 + ISAC 通信约束，更复杂。**搜索框架对内层方法是黑箱（只需 design oracle）**，可先用现有方法跑通搜索，再评估是否升级。

### 6.5 WJPS 迁移的权重与误差范围

权重 `ω_m`（含对称性）、误差范围半径 `Δ`、离散点数 `M_e` 均待定。注意：误差范围对称而权重随 |误差| 单调增时，需明确 m 的索引方式（有符号 vs 绝对值），避免设计偏向一侧——实测退化是**不对称**的（负误差侧更差）。矩阵链见附录 B。

### 6.6 已结案

- ~~归一化分母依赖优化、可能虚低~~：分母由 `x^H h = b_max = N` 硬约束钉死（§2.3）。
- ~~多谷导致二分法失效~~：已有实测支持单峰；且真正风险是评估噪声而非多谷（§6.3）。

## 附录 B：WJPS 迁移到采样周期误差的矩阵链

> 本节按"改干扰模型必须写明 `H_j`/`X_j` 构造"的约定给出。此扩展**尚未实现**。

**信号级**（第 `m` 个误差点的参数 `θ_m`，采样函数 `j_m = j(θ_m)`）：

```
y_{j,m} = x ⊙ j_m = diag(j_m)·x
r_{j,m} = H·y_{j,m} = H·diag(j_m)·x
```

**矩阵链**：

```
H_{j,m}        := H·diag(j_m)                       （ISRJ 卷积矩阵，逐点）
H_{j,m}^H H_{j,m} = diag(j_m)·(H^H H)·diag(j_m)      （快速组装用）
                 = diag(j_m)·Toeplitz(r_h)·diag(j_m)
X_{j,m}^H X_{j,m} = Toeplitz(r_{x⊙j_m})              （X_{j,m} 由 x⊙j_m 铺成，不是 diag(j_m)X^H X diag(j_m)）
```

**目标矩阵**（`ω_m` 为权重，`Σ_m ω_m = 1`）：

```
P_WJPS = ε·H^H D H + (1−ε)·Σ_m ω_m · H_{j,m}^H H_{j,m}
       = ε·(Toeplitz(r_h) − h h^H) + (1−ε)·Σ_m ω_m · [Toeplitz(r_h) ⊙ (j_m j_m^T)]

Q_WJPS = ε·X^H D X + (1−ε)·Σ_m ω_m · X_{j,m}^H X_{j,m}
       = ε·(Toeplitz(r_x) − x x^H) + (1−ε)·Σ_m ω_m · Toeplitz(r_{x⊙j_m})
```

即：WJPS 只把原来的**单个**掩膜项 `T ⊙ (j j^T)` 换成误差点上的一族加权和。

**约束的连带改动**：单约束 `x_j^H h = b_min` 需推广为对每个误差点的约束（`M_e` 个线性约束），或加权松弛（`|x_{j,m}^H h| ≤ b_min`）。实现后果：模块三的闭式解从 2 约束变为 `M_e + 1` 约束的 KKT 系统。

**权重**：`ω_m` 待定（候选方案：对称距离加权 `ω_m ∝ |误差_m|`；按实测退化曲线定权；原文 `ω_m = m/Σm` 待核实）。
