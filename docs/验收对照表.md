# 验收对照表

> 本项目验收以五个 PRD 为唯一权威（PRD_01 ~ PRD_05）。下表逐条列出各 PRD 的
> 验收标准、本实现的实测数值与结论。实测数据来自 2026-08-25 全规模运行
> （N=800, M=100, ρ=5000, ε=0.5）及 39 项 pytest 测试（`tests/`，每个测试
> docstring 标注对应条款）。
>
> 结论列：✅ 通过 / ✳️ 通过但有口径说明 / ⚠️ 偏差（已在 CLAUDE.md"已知偏差"如实记录）

## 已确认偏差汇总（详见 CLAUDE.md"已知偏差"）

1. **处理增益损失 −2.49 dB**（随机相位默认初始化），论文报告 −0.9 dB；差异为
   旁瓣抑制的代价（最小范数滤波器理论上界 −0.77 dB），非数值误差。`--init lfm`
   下 −0.85 dB，与论文吻合，但 PSL 差约 5–10 dB。
2. 图 3(a) 单调趋势只在 `--init lfm` 下成立（PRD 验收 6.3-3 的默认口径为偏差）。
3. 外层前 1–2 轮 ADMM consensus 触顶（预热现象，非 bug）。
