## 时间线

### 阶段 1：PRD 文档集制定（2026-08-23）

对照论文原文制定五份 PRD（PRD_01 ~ PRD_05），每个模块对应一份：

| PRD | 覆盖内容 | 关键产出 |
|-----|----------|----------|
| PRD_01 | 全局参数、ISRJ 采样函数、变量初始化 | N=800 的论证（图 1(b) 横轴佐证）、max_inner_iter=500 |
| PRD_02 | H/X/H_j/X_j/D 矩阵、P/Q 加权矩阵 | Toeplitz 快速组装公式（§4.3） |
| PRD_03 | 拉格朗日闭式解 h | **式(8) 排版勘误**：印刷版漏 `Q^{-1}x_j` 项且漏共轭（§3.4） |
| PRD_04 | ADMM 波形求解 | `A = 2P + 2ρI + …` 的 2P 系数、收敛判据为范数和 |
| PRD_05 | Algorithm 1、图 1–3 规格 | 热启动、图 4 确认不实现 |

PRD 的"已确认事项"小节成为裁决机制：论文含糊/出错处以 PRD 为准。

### 阶段 2：五模块实现（2026-08-25）

按 PRD 顺序实现 `isrj_joint_design` 包（params / matrices / filter_solver /
waveform_admm / joint_design / plotting），每模块配验收测试（每测试 docstring 标注
PRD 条款）。实现期间发现并解决两个**建模层问题**：

1. **矩阵共轭约定**：PRD_02 的图示（不带共轭）与验收 2（峰值 = h^H x）数学互斥，
   推导后取带共轭（决策 [ADR-0001](adr/0001-矩阵共轭约定.md)，CLAUDE.md 决策 #1）。
2. **ADMM 只接可行的 h**：随机单位模 h 下约束集为空（Cauchy–Schwarz 迫使 x=h，
   与 b_min 矛盾），测试起初全挂；定位后确认求解器无 bug——真实 Algorithm 1 先解 h
   再进 ADMM，测试 fixture 改为同构构造后全过（CLAUDE.md 决策 #8）。

### 阶段 3：全规模复现与验收（2026-08-25）

N=800、M=100 全规模运行（58 秒），生成论文图 1–3。验收结果：

| 指标 | 实测 | 论文/PRD 要求 |
|---|---|---|
| 处理增益损失 | −2.49 dB | −0.9 dB（⚠️ 偏差，见阶段 4） |
| PSL | −31.6 dB | < −20 dB ✓ |
| ISRJ 零延迟电平 | −30.00 dB | ≤ −30 dB ✓ |
| PAPR | 1.1000 | ≤ 1.1 ✓ |
| 主瓣/干扰约束残差 | 4.7e-10 / 2.9e-8 | < 1e-4 ✓ |
| 内层 ADMM consensus | 每轮 < 1e-4 | < 1e-4 ✓ |

39 项测试全过；PAPR 扫描完成（图 3(b) ISLs/ILs 单调下降成立）。

### 阶段 4：处理增益损失偏差调查（2026-08-25）

追查 −2.49 dB vs 论文 −0.9 dB 的成因，形成完整证据链（详见 CLAUDE.md"已知偏差"、
[ADR-0003](adr/0003-处理增益损失验收口径.md)）：

1. 损失第 1 次外层迭代即定型（与收敛无关），M=25 与 M=100 无差别；
2. ε 探测：ε=0.1 → −1.95 dB（PSL −22.8），ε=0.9 → −3.58 dB——ε 是真实杠杆但论文
   明确写 0.5；
3. **最小范数上界**：只满足两个峰值约束的滤波器损失 −0.77 dB（推导：
   `loss = 10log10(N/||h||²)`，旁瓣抑制只会增大 ||h||²）——论文 −0.9 dB 与该上界同
   量级，−2.5 dB 是旁瓣抑制（PSL −31.6 dB）的代价；
4. **LFM 初始化发现**：`init="lfm"` 使损失降到 −0.84 dB 且随 PAPR 单调改善
   （−1.32 → −0.50 dB，完全复现论文图 3(a) 趋势），代价 PSL 差 5–10 dB——论文数值
   对应"低旁瓣要求较松的局部最优"，初始化决定落在哪个盆地。

结论：如实记录偏差，不添加 PRD 未规定的旋钮凑数；四嫌疑（屏蔽区宽度、ε、滤波器长度、
外层判据）列为备选任务（其中外层判据已被数据排除）。

### 阶段 5：实验扩展（2026-08-25 ~ 08-30）

在"PRD 权威 + 实验旋钮显式覆盖"的口径下扩展干扰模型：

| # | 实验 | 关键结果 |
|---|------|----------|
| 1 | 采样窗口 [0.25, 0.5) μs（占空比 2.5%） | PSL −41.4 dB（改善 10 dB）、损失 −3.05 dB——**占空比决定设计难度** |
| 2 | 窗口平移 [2.5, 5) μs（占空比不变） | 指标在种子波动内（零结果）——**窗口位置无关**；但 ADMM 变慢（耗时 58→120 s，条件数变差） |
| 3 | 默认窗口改为 [2.5, 5) μs | 用户指定实验默认（[ADR-0004](adr/0004-默认采样窗口位置.md)），PRD 基线用 tau_offset=0 恢复 |
| 3b | 默认窗口恢复 PRD 基线 [0, 2.5) μs（2026-08-30） | 用户要求恢复：`tau_offset` 默认回 0.0、`retransmit_offsets` 回 (0.0,) 单份零延迟；ADR-0004 标记 deprecated；评估脚本显式钉住自己的实验口径，不受默认值影响 |
| 4 | 双转发评估（边采样边转发 + 10 μs 后二次转发，T_s=20 μs） | 评估侧实现：干扰矩阵 `J_multi = (I+S_200)·diag(j)`；双转发输出峰值 −30.49 dB（仍达标）、能量比 1.984——**现有设计对双转发天然免疫**（第二份输出 = 第一份输出平移 200 点，落在已压低的旁瓣上） |
| 5 | 双转发改为"截取完成后转发"（转发#1 偏移 2.5 μs = 50 点，转发#2 仍 10 μs） | 干扰矩阵 `J_multi = (S_50+S_200)·diag(j)`；峰值 **−28.88 dB，相对无误差基准 −30 dB 退化 1.12 dB**——时延把转发主瓣移出零延迟约束位，单份输出在负向滞后（−50 点附近）的强旁瓣（约 −32 dB，正向滞后则 < −46 dB，不对称）被搬进零延迟区 |
