# 0004: 默认采样窗口设为 [2.5, 5) μs（tau_offset=2.5e-6），偏离 PRD 基线 [0, 2.5) μs

> **Status: deprecated**（2026-08-30 用户要求恢复 PRD 基线：`tau_offset` 默认回到 0.0，
> 即窗口 [0, 2.5) μs。本文件保留为历史决策记录。）

PRD_01 §3.2 的采样函数是每周期从 0 开始的 2.5 μs 窗口；用户 2026-08-25 指定默认窗口改为
每周期 [2.5, 5) μs（起点 2.5 μs、宽度不变、占空比 0.25）作为实验设定。我们决定：`tau_offset`
默认值 2.5e-6，PRD 基线用 `tau_offset=0` 显式恢复（CLI `--tau-offset 0`），测试与文档同步
标注两条口径。

- **Considered Options**: 保持默认 0、每次实验显式传参——用户明确要求"按 [2.5, 5) μs 生成"，
  故改默认；不改测试口径——会使 PRD 验收测试静默偏离 PRD，否决（验收测试显式用 tau_offset=0）。
- **Consequences**: 纯平移对指标无统计影响（损失 −2.49→−2.51 dB、PSL −31.6→−31.9 dB，在
  种子波动内），但内层 ADMM 迭代变慢、总耗时约翻倍（h_j 支撑移到中间带，A 的条件数变差）；
  0.25 μs 窄窗口实验另证"占空比决定设计难度、窗口位置无关"。
