# 0005: 展宽度量口径 —— 在假目标 lag 上读电平

> **Status: accepted**（2026-10-17 用户拍板）

"把尖峰 V 扩成平缓 V"里的"电平"，定义为**假目标所在距离格子上的电平**：

```
C(θ̂) = max_{ℓ ∈ 假目标 lag} | ⟨h(θ̂), v_ℓ(θ*)⟩ | / | ⟨h(θ̂), x(θ̂)⟩ |
```

其中假目标 lag 由干扰模型 `d_r = r·T_L` 给出（重复转发），位置由参数经模型**预测**，不是真值。前提是场景干扰模型取"重复转发"（假目标固定在 +15/+30/+45 采样点），不取"零延迟原位"。

- **Considered Options**: 另一种口径是读**全延迟峰值**（整条距离轴上的最大值）。实测否决：该口径下 V 只有 11 dB 深（±0.2 μs 内 −33.6 → −22.2），本来就不尖，展宽没有意义；而且复合约束、电平块两种方法都压不动它。假目标位置口径下 V 是针尖（−80 → −23，57 dB），正是要解决的问题；且雷达在第一步设计时本来就持有 θ̂，能由模型预测位置，不依赖真值。
- **Consequences**: ① [搜索线规格说明](../../参数搜索/docs/搜索线规格说明.md) §2.2 分子里的 `max_k`（全延迟峰值）需要改成"在假目标 lag 上取最大"；② 汇报与文档中必须写明"位置来自模型预测，不是真值"；③ 取法不同会让结论完全翻转 —— 以后讨论"展宽效果"必须先声明口径。
