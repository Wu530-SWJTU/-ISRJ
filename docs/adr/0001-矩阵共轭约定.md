# 0001: 卷积/互相关矩阵采用共轭序列铺成

PRD_02 的图示（不带共轭）与验收 2（主瓣峰值 = `h^H x`，带共轭）数学上互斥——`H x` 对
`h` 共轭线性，不可能同时等于对 `h` 线性的 `X h`。我们决定让 `H[k,n]=conj(h[k-N+n])`、
`X[k,n]=conj(x[N+n-k])`，即**带共轭**的矩阵，使主瓣峰值严格等于 PRD 的 `h^H x`/`x^H h`，
与模块三/四/五的全部公式及雷达匹配滤波物理自洽；代价是 `H x = conj(X h)`（PRD_02 §7
验收 1 的"Hx 与 Xh 数值一致"在本实现中解释为"共轭一致"）。

- **Considered Options**: (A) 不带共轭（PRD 图示直译）——`Hx = Xh` 精确成立，但峰值变成
  `h^T x`，与全部下游公式（`x^H h`、`b_max` 约束、ADMM 的 `ρhh^H` 项）冲突；(B) 带共轭
  （本实现）——唯一同时满足验收 2 与下游公式的取法；(C) 一边带一边不带——两边都错。
- **Consequences**: 只有 `matrices.py` 的矩阵元素定义带 conj，模块三/四/五公式与 PRD 原文
  逐字一致；`x^H P x == h^H Q h` 严格成立（D 为实对角阵保证）。显式构造与 FFT 快速路径
  由 `test_matrices.py` 锁定等价性。
