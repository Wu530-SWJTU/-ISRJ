# 0007: WJPS 族设计 —— κ 只做归一化，γ 只做比例

> **Status: accepted**（2026-10-17 用户拍板）
>
> **更新（2026-10-25）**：γ 的取值与权重方向已由 **ADR-0010** 修订 —— γ 改为 **0.6**，
> 权重改为**中心加权 1:3:6:3:1**（自然顺序）。本文件锁定的归一化结构与旋钮结构不变。

目标函数里要把**能量块** `E`（511 个格子的干扰能量）与**电平块** `L`（逐档假目标电平，见 ADR-0006）混合。两者量级差约 1000 倍（`trace(E) ≈ 3.2e4`，`trace(L) ≈ 28`），必须归一化。决定：

```
κ  = trace(E) / trace(L)              ← 固定的归一化因子，不是可调参数
L̂  = κ · L                            ← 与能量块同量级
干扰项 = (1−γ)·E + γ·L̂                ← γ 是唯一的比例旋钮
Q = ε·(T_x − x x^H) + (1−ε)·[(1−γ)·E + γ·L̂]
```

关键性质：**γ = 0 严格等于现有设计**（实测 `max|Q − Q_现有| = 0`）。

- **Considered Options**: ① **旧归一化**（两块都对齐到 ISL 块的 trace）——导致 γ=0 不等于现有设计（实测差 65.5），旋钮失去零点，否决。② **无上限的倍率形式** `E + κ·L̂`（κ 可调）——能压得更深，但完整联合设计下 κ=100 出现"中心最差"的**倒挂**（零误差 −80、误差档 −90），且 γ 的比例含义被总强度干扰，暂不用。③ **γ 唯一**——采用。
- **Consequences**: ① 参数只有一个 γ；κ 由 trace 决定，实现时不能当旋钮调。② 权重 `ω_m ∝ 1+|Δ_m|`（误差越大权重越大，对齐 Zhou 2026 `ω_m = m/Σm` 的对称版，实际取 3:2:1:2:3）。③ **γ = 0.3 已定（2026-10-17 用户拍板）**；配套约束为复合约束（ADR-0008），b_min = −50 dB（ADR-0009）。最终实测（`T_s` 轴 ±0.2 μs，完整 (x,h) 联合设计）：五档 −43.0 ~ −46.1 dB（起伏 3.1 dB）、中心 −44.4 dB、PSL −29.38 dB、LPG −4.00 dB。④ **权重形式与三参数全盒（125 档）仍未定**；现权重会让 ±2 档被压得比 ±1 档更低，底部不严格单调。
