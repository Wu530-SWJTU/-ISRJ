# 0006: 电平块用逐档平方和，不用式 (22) 的合成后平方

> **Status: accepted**（2026-10-17 用户拍板）

Zhou 2026 式 (20)–(22) 把所有误差档的干扰信号**加权合成一个信号**，再对合成信号的峰值做约束。把它改写成目标函数里的软项时有两种写法：

```
逐档平方和（采用）：  L = Σ_m ω_m Σ_ℓ v_{ℓ,m} v_{ℓ,m}^H     →  h^H L h = Σ_m ω_m |⟨h, v_{ℓ,m}⟩|²
合成后平方（否决）：  L = Σ_ℓ ū_ℓ ū_ℓ^H,  ū_ℓ = Σ_m ω_m v_{ℓ,m}
                                                        →  h^H L h = Σ_ℓ |Σ_m ω_m ⟨h, v_{ℓ,m}⟩|²
```

决定采用**逐档平方和**。

- **Considered Options**: 合成后平方严格对齐式 (22)，但它存在**相位对消**——`|Σ_m ω_m⟨h, v_m⟩|` 可以很小，而每个 `|⟨h, v_m⟩|` 仍然很大；优化器会利用这一点，逐档压不实。实测（`T_s` 轴 ±0.2 μs，精确约束，h-only，γ=1）：合成写法逐档最差 **−29.4 dB**；逐档写法（完整 (x,h) 联合设计，γ=0.6）最差 **−46.4 dB**，差 17 dB。另外，论文式 (22) 本身是等式约束而非目标项，改成软项后相位对消的弱点才暴露。
- **Consequences**: ① 与论文式 (22) 形式不同，汇报中需说明这是**有意偏离**及实测理由；② 逐档写法在 `T_s` 一维是 15 个秩 1 项（5 档 × 3 个假目标），三参数全盒为 340 项（35 档转发份数 R=2），计算与内存均可接受；③ 硬钉每档假目标格子效果最好（全 −80）但三维约束数 375 > N=256 不可行，且用户明确排除，故只能走软项。
