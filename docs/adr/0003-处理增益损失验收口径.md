# 0003: 处理增益损失按"PRD 权威 + 如实记录偏差"处理，不强行对齐论文数值

全规模实测（2026-08-25，N=800/M=100）：PRD 指定的随机相位初始化下损失 −2.5 dB，论文
报告 −0.9 dB，超出 PRD_05 §6.1 的 ±0.5 dB 容差。调查证明这不是数值误差：只满足两个峰
值约束的最小范数滤波器损失 −0.77 dB（该指标的**理论上界**，`loss = 10log10(N/||h||²)`），
旁瓣/干扰抑制必然使 ||h||² 增大、损失变差；`init="lfm"` 时损失 −0.84 dB 且随 PAPR 单调
改善（与论文图 3(a) 趋势一致，代价 PSL 差 5–10 dB）。我们决定：验收以 PRD 为准，损失偏差
在 CLAUDE.md"已知偏差"与 docs/验收对照表.md 中如实记录，**不添加 PRD 未规定的正则化旋钮
凑数**。

- **Considered Options**: 加滤波器范数惩罚等未规定旋钮逼近 −0.9 dB——违背 PRD 唯一权威原则，
  被否决；把 `init="lfm"` 设为默认——同样违背 PRD_01 §4.1，LFM 仅保留为显式开关。
- **Consequences**: 已知偏差证据链（ε 探测、min-norm 上界、种子极差、LFM 对照）全部记录在
  CLAUDE.md；四嫌疑深挖实验列为"备选后续任务"（用户 2026-08-25 拍板暂缓）。
