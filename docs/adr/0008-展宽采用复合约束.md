# 0008: 展宽采用复合约束（式 22），不保留精确约束

> **Status: accepted**（2026-10-17 用户拍板）

族设计的等式约束有两种取法：

```
精确约束（否决）：  ⟨h, v_ℓ(θ̂)⟩ = b_min,      ℓ ∈ {0, +15, +30, +45}   ← 用精确参数的掩膜
复合约束（采用）：  ⟨h, v_ℓ(ĵ)⟩ = b_min,       ĵ = Σ_m ω_m j_m           ← 式(20)(21) 的合成掩膜
```

决定采用**复合约束**，不再把精确参数的假目标电平钉在 −80 dB。

- **Considered Options**: 精确约束会把零误差档的假目标电平**焊死在 −80 dB**（等式约束），等于宣称"覆盖误差范围不付代价"。实测：保留精确约束时，损失只能转嫁到 LPG（−2.91 → −3.24 dB）与能量项份额；曲线呈"中心 −80 尖峰 + 底部 W 形"（±2 档 −54、±1 档 −46），不是平缓 V。复合约束让中心与误差档一起承担损失，曲线变成均匀平底。用户 2026-10-17 明确要求"不要精确约束"。
- **Consequences**: ① **零误差档不再有 −80 dB 的硬保障**：实测（`T_s` 轴 ±0.2 μs，完整 (x,h) 联合设计，γ=0.3）中心从 −80 抬到 −45.0 dB，这是有意接受的损失；② 好处是形状从"尖峰 + W"变成均匀平底（五档 −41.6 ~ −48.3 dB，起伏 5.7 dB），PSL 同时改善到 −29.54 dB；③ lag 0（真目标格子的保护）仍留在约束集合里，未受影响。
