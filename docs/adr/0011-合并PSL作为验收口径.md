# 0011: 旁瓣验收口径改为「信号 + 干扰」的合并 PSL

> **Status: accepted**（2026-10-25 用户拍板）

## 背景

雷达实际看到的距离像是**真目标回波与干扰的合成**：

```
r_total = r_sig + a_J · r_jam
```

其中 `r_sig = x ⊛ h`（信号路径）、`r_jam = u ⊛ h`、`u = Σ_r shift_{d_r}(x ⊙ j)`（干扰路径）、
`a_J = 10^(J/S/20)`（场景 J/S = 10 dB ⇒ a_J = 3.16）。

此前只报 `r_sig` 的 PSL（"波形自身旁瓣"），**忽略了干扰泄漏**。而干扰响应除假目标外的
那 2N−2 个点，在距离像上同样是旁瓣 —— 只报信号旁瓣是不完整的。用户 2026-10-25 指出
这一口径问题。

## 决定

- **验收/报告口径改为合并 PSL**：

```
PSL_total = max_{k ≠ N} |r_total[k]| / | h^H x |
```

- 信号 PSL 与干扰 PSL 仍分别报告，用于归因。
- 合并是**相干相加（复数）**，不是能量相加；相位决定叠加或抵消。
- 干扰幅度按场景 J/S 计入（当前 10 dB）。

实测（权重 1:3:6:3:1，h-only，b_min=−50，复合约束）：

| γ | 信号自身 PSL | 干扰自身 PSL | **合并 PSL** | 合并最差点 |
|---|---|---|---|---|
| 0 | −24.06 | −33.68 | **−20.56** | lag −15 |
| 0.3 | −25.10 | −33.26 | **−21.30** | lag −15 |
| **0.6** | −26.31 | −32.73 | **−21.97** | lag −15 |
| 1.0 | −27.08 | −30.93 | **−20.54** | lag −125 |

## 后果

- **合并 PSL 比信号 PSL 差 3~5 dB**。以后验收用合并值，不能再只报 −24 ~ −27 dB。
- **γ=0.6 在合并口径下也是最优**（−21.97 dB）；γ=0 与 γ=1.0 都在 −20.5 dB 附近，
  比最优点差约 1.4 dB。
- 合并 PSL 由**两块的合力**决定：信号旁瓣（ISL 项）与干扰泄漏（能量块）。这也是
  §6.1"把 2N−1 个点拆成两部分"的物理依据 —— 两边都会出现在同一张距离像上。
- 由于是相干相加，**最坏相位**可能比当前实测更差；报告里应注明这是实际接收数据的
  相干结果，不是上界。
