# 0002: 滤波器闭式解采用"两项含共轭"形式（修正论文式(8) 排版错误）

论文印刷版式(8) 遗漏 `Q^{-1}x_j` 项、且第二项系数漏共轭；按印刷版实现会导致第二个约束
`x_j^H h = b_min` 一般无法满足。我们决定采用数学上正确的**两项含共轭**形式
`h = (1/D)[(b_max·c − b_min·b)Q^{-1}x + (b_min·a − b_max·conj(b))Q^{-1}x_j]`（PRD_03
§3.4 的勘误小节，与 PRD 一致）。

- **Considered Options**: 按论文印刷版单项实现——代入约束验证得
  `x^H h = b_max(ac − b²)/D`，当 b 为复数时 `b² ≠ |b|²`，约束不满足；两项含共轭形式代入
  得 `b_max(ac−|b|²)/D = b_max` ✓。
- **Consequences**: 测试 `test_matches_kkt_linear_system_solution` 用独立 KKT 线性方程
  组解法交叉验证本实现，防止未来有人"改回论文印刷版"。
